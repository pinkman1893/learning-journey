# CSS 定位布局

## 定位的组成

定位由定位模式和边偏移组成：

- 定位模式决定元素在文档中的定位方式。
- 边偏移决定元素的最终位置。

```css
position: static | relative | absolute | fixed | sticky;
```

## 定位模式

### 静态定位 `static`

静态定位是默认定位方式，元素按照标准流摆放，很少单独使用。

### 相对定位 `relative`

相对定位让元素相对于原来的位置移动。可以理解为“魂儿移动了，实体仍留在原来的位置”：元素仍占有原来的空间，后续盒子继续按标准流对待它的原位置。

### 绝对定位 `absolute`

绝对定位让元素相对于祖先元素移动：

- 如果没有祖先元素或祖先元素没有定位，则以浏览器可视区域为参照。
- 如果祖先元素有定位，则以最近一级已定位的祖先元素为参照。
- 绝对定位脱离标准流，不再占有原来的位置。

常用口诀是“子绝父相”：子元素使用绝对定位时，父元素使用相对定位。这样子元素可以在父盒子内自由定位且不占位置，父盒子仍然占有原来的位置。

### 固定定位 `fixed`

固定定位把元素固定在浏览器的某个位置，页面滚动时位置不会改变：

- 以浏览器可视窗口为参照，与父元素位置无关。
- 固定定位脱离标准流。

将元素固定在页面版心右侧的思路：

1. 设置 `left: 50%`，让盒子左侧移动到可视区中间。
2. 设置 `margin-left` 为版心宽度的一半，让盒子移动到版心右侧。

### 粘性定位 `sticky`

粘性定位可以看作相对定位和固定定位的混合：

- 占有原来的位置。
- 以浏览器可视窗口为参照移动元素。
- 必须添加 `top`、`bottom`、`left`、`right` 中的至少一个才会生效。

## 边偏移

`top`、`bottom`、`left`、`right` 用于定义元素相对于参照边线的距离。

## `z-index` 属性

当盒子重叠时，使用 `z-index` 调整前后显示顺序：

- 默认值为 `auto`，书写顺序靠后的元素显示在上方。
- 可以使用正整数或负整数，数值越大越靠上。
- 数值后不能添加单位。
- 原笔记主要把它用于已经定位的盒子。

## 定位拓展

### 绝对定位盒子居中

绝对定位盒子不能直接使用 `margin: 0 auto` 实现水平居中，可以按以下方式设置。

水平居中：

1. 设置 `left: 50%`，让盒子左侧移动到父盒子的水平中心。
2. 设置负的 `margin-left`，向左移动自身宽度的一半。

垂直居中：

1. 设置 `top: 50%`。
2. 设置负的 `margin-top`，向上移动自身高度的一半。

### 定位元素的尺寸特性

绝对定位和固定定位与浮动有一些相似特性：

1. 行内元素添加绝对定位或固定定位后，可以直接设置宽度和高度。
2. 块级元素添加绝对定位或固定定位后，如果不设置宽高，默认大小由内容决定。

### 脱离标准流与覆盖关系

- 浮动、绝对定位和固定定位元素不会触发外边距合并。
- 浮动元素会覆盖下面标准流盒子的背景，但不会覆盖其中的文字和图片，这与浮动最初用于文字环绕有关。
- 绝对定位和固定定位元素会覆盖下面标准流盒子的全部内容。
