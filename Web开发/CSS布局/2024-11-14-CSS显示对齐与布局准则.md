# CSS 显示、对齐与布局准则

## 元素的显示与隐藏

常见场景包括关闭广告、鼠标悬停时显示以及移开后隐藏。

### `display`

`display` 用于设置元素如何显示。

```css
display: none;
```

隐藏元素，并且不保留原来的位置。

```css
display: block;
```

除了把元素转换为块级元素，也可以用于重新显示元素。该属性常与 JavaScript 搭配形成网页效果。

### `visibility`

`visibility` 用于设置元素是否可见。

```css
visibility: hidden;
```

隐藏元素，但保留原来的位置。

```css
visibility: visible;
```

让元素可见。

### `overflow`

`overflow` 用于指定内容超出元素规定宽高时的处理方式。

## `vertical-align` 属性

### 使用场景

1. 设置图片、表单等行内块元素与文字的垂直对齐方式。
2. 解决图片底部出现白色缝隙的问题。

该属性主要对行内元素和行内块元素有效。

```css
vertical-align: baseline | top | middle | bottom;
```

<img src="assets/display-align-layout/be1e3940bdba.png" alt="vertical-align 属性值示意图">

<img src="assets/display-align-layout/1eba6ab46d9c.png" alt="图片与文字的基线对齐示意图">

图片和文字默认使用基线对齐。图片底部出现白色缝隙，是因为行内块元素默认与文字基线对齐。

<img src="assets/display-align-layout/4b974bfdd115.png" alt="图片底部白色缝隙示意图">

解决方法：

1. 给图片设置 `vertical-align: middle`、`top` 或 `bottom`。
2. 把图片转换为块级元素：`display: block`。
