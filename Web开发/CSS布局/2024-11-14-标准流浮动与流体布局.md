# 标准流、浮动与流体布局

## 流体盒子

流体盒子（Fluid Box）是指在 CSS 布局中，通过设置元素的宽度和高度为百分比或其他响应式单位，使元素能够自适应父容器的大小。流体盒子在响应式设计中很重要，可以让布局根据不同屏幕尺寸灵活调整。

```html
<style>
  .container {
    width: 80%;
    margin: 0 auto;
    border: 1px solid black;
  }

  .fluid-box {
    width: 50%;
    height: 100px;
    background-color: lightblue;
  }
</style>
```

## 标准流

标准流又称普通流、文档流，元素按照默认方式排列。

## 浮动布局

### 语法

```css
选择器 {
  float: none | left | right;
}
```

### 浮动特性

- 浮动元素会脱离标准流，不再保留原来的位置，并移动到指定位置。
- 浮动盒子只会影响它之后的标准流盒子，不会影响之前的标准流盒子。
- 多个浮动元素会在一行内显示，并且顶部对齐。
- 浮动元素具有行内块元素的部分特性，实际宽高可以由内容决定。

### 与标准流父级搭配

浮动元素常与标准流父级搭配使用，从而约束浮动元素的位置：先用标准流父元素排列上下位置，再让内部子元素通过浮动左右排列。

### 清除浮动

适用情况：

1. 父级元素不方便设置固定高度。
2. 浮动元素脱离标准流、不占用原文档位置并对排版产生影响。

清除浮动的本质是闭合浮动，消除浮动造成的影响。父元素未设置高度时，清除浮动后可以根据内部浮动盒子调整高度。

```css
选择器 {
  clear: left | right | both;
}
```

常见方法：

1. 额外标签法：在最后一个浮动盒子后添加新盒子，并设置 `clear: both`，也可以使用 `br` 换行。
2. 给父元素添加 `overflow: hidden`、`auto` 或 `scroll`；缺点是可能无法显示溢出的部分。
3. 给父元素添加 `::after` 伪元素。
4. 给父元素添加双伪元素。
