# Web 前端实训技巧

## 2024-11-19

### 只改变列表项目符号的颜色

可以给列表设置项目符号颜色，再使用列表项中的元素恢复文字颜色。

```html
<style>
  .box ul {
    color: red;
    padding-top: 20px;
  }

  .box ul li p {
    color: black;
    font-size: 16px;
    margin-bottom: 5px;
  }
</style>

<div class="box">
  <ul>
    <li><p>技术应用升级 百所高校 IPv6 蝶变</p></li>
    <li><p>教育信息化服务器应用突破壁垒</p></li>
    <li><p>教育信息化关注“十二五”规划</p></li>
    <li><p>强调应用 移动 IPv6 发展空间无限</p></li>
  </ul>
</div>
```

### 控制文本首行缩进

```html
<style>
  .article p {
    text-indent: 2em;
    margin-bottom: 30px;
  }
</style>

<div class="article">
  <p>
    2004年12月，《中国教育网络》杂志正式出版发行。经国家新闻出版署、科技部批准，教育部主管，教育部科技发展中心主办，中国教育和科研计算机网（CERNET）承办的国家级权威科技期刊《中国教育网络》正式出版发行。
  </p>
  <p>
    立足教育网络，服务于教育信息化，《中国教育网络》关注和解读国家信息化发展政策，全面报道中国教育网络建设现状及成就，研究探讨教育网络建设的经验与问题。介绍国际上先进的网络技术、理念，及时报道相关政策及重大事件，广泛反映围绕教育信息化的各种重大应用及重大事件，为领导、专家、师生及技术人员提供借鉴。
  </p>
  <p>
    依托高校及社会各界的优秀专家，《中国教育网络》突出权威性、政策性、前瞻性，为专家及业界人士提供一个权威的交流与沟通平台。《中国教育网络》已成为中国最具影响力、权威性的专业期刊，已成为与中国教育信息化同步发展的核心媒体。
  </p>
</div>
```

每一个 `<p>` 标签代表一个段落。

### 调整行间距与段间距

行间距：

```css
line-height: 20px;
```

段间距：

```css
margin-bottom: 20px;
```

### 文本加粗与下划线

- 下划线等文本装饰使用 `text-decoration`。
- 文本加粗使用 `font-weight`。

### 设置字符间距

使用 CSS 的 `letter-spacing` 属性。

## 2024-11-21

### 清除默认内外边距

制作网页前，可以先清除元素默认的内外边距：

```html
<style>
  * {
    margin: 0;
    padding: 0;
  }
</style>
```

### 让单行文字在盒子中水平、垂直居中

- 水平居中：`text-align: center;`
- 垂直居中：设置文字的 `line-height` 与盒子的 `height` 相等。

### 不同显示类型元素的水平居中

- 块元素：`margin: 0 auto;`
- 行内元素和行内块元素：给父级盒子设置 `text-align: center;`。

## 2024-11-25

### 表格的基本 CSS 设置

- 给 `table`、`th`、`td` 设置边框后，合并相邻边框。
- 给 `th` 设置 `padding`。
- 给 `table` 设置 `text-align: center`，让文本水平居中。

```html
<style>
  table,
  td,
  th {
    border: 2px solid black;
  }

  table {
    border-collapse: collapse;
    height: 80px;
    margin: 0 auto;
    text-align: center;
  }

  th {
    padding: 5px 30px;
  }
</style>
```

## 2024-11-27

### `margin: 0 auto` 的生效条件

- 目标通常为块级元素。
- 目标元素需要具有小于父容器可用宽度的计算宽度。
- 宽度可以使用固定值，也可以使用百分比。

### 防止导航栏自动换行

给父元素添加：

```css
white-space: nowrap;
```

### 防止元素在窗口缩小时过于拥挤

为元素设置最小宽度：

```css
min-width: 800px;
```

当元素宽度小于指定的最小宽度时，浏览器会保持该最小宽度，避免元素缩得过小；这也可以防止浮动盒子在窗口缩小时被挤到下一行。

### 左侧固定、右侧自适应

```css
.left {
  width: 200px;
}

.right {
  width: calc(100% - 200px);
}
```
