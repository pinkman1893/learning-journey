# 960 Grid 布局

## 为什么使用 960px

- 不同电脑显示器的大小和分辨率不同。
- 960px 曾是常见的固定宽度，并且可以被 12、16 等列数整除，便于构建网格系统。

## 引入框架文件

```html
<link rel="stylesheet" href="960.css">
<link rel="stylesheet" href="reset.css">
<link rel="stylesheet" href="text.css">
```

- `960.css` 是主要排版样式文件。
- `reset.css` 用于消除 HTML 标签在不同浏览器中的默认样式差异。
- `text.css` 主要用于统一字体和文本样式。
- 不要直接修改框架源文件。

## 确定大容器

- 使用 `.container_12` 或 `.container_16` 作为大容器。
- 它们分别把 960px 宽度划分成 12 列或 16 列。

## 设置网格

- 使用 `grid_n` 类设置元素占据的列数，其中 `n` 表示在一行 12 或 16 列中占几列。
- 网格宽度由框架确定，使用时主要设置内容和高度。
- 原笔记也记录了每完成一行后用 `<br>` 隔断。
- 每完成一行横向布局，可以添加类名为 `clear` 的元素清除这一行对后续布局的影响。

## 清除左右边距

默认情况下，每个网格块的左右外边距各为 10px，因此相邻列之间的间距为 20px。

- 最左侧网格添加 `alpha`，去掉左外边距。
- 最右侧网格添加 `omega`，去掉右外边距。

## 完整示例

```html
<div class="container_12">
  <div class="grid_2 alpha"></div>
  <div class="grid_6"></div>
  <div class="grid_2"></div>
  <div class="grid_2 omega"></div>
</div>
```
