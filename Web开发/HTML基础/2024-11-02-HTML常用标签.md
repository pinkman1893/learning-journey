# HTML 常用标签

## `div` 与 `span` 标签

`div` 和 `span` 标签没有语义，主要作为盒子组织内容。

- `div`：`division`，表示分区，是用于组织内容的块级标签。它可以看作大盒子，一行只能放一个 `div`。
- `span`：表示跨度、跨距，用于包装一小部分文本，以便使用 CSS、JavaScript 等工具处理；它可以看作小盒子，可以横向显示多个 `span`。

表格 `table` 本身可以看作大盒子，其中的 `td`、`th` 是一个个小盒子。

### `div` 标签

`div` 后面可以添加 `class`、`id` 等属性：

```html
<div class="类名"></div>
```

Emmet 快捷写法：

- 带 `class` 的 `div`：输入 `.类名` 或 `div.类名` 后按 `Tab` 键。
- 带 `id` 的 `div`：输入 `#id名` 或 `div#id名` 后按 `Tab` 键。

### `span` 标签

```html
<span>文本内容</span>
```

## 链接标签

链接可以分为以下几种：

1. 外部链接。
2. 内部链接。
3. 空链接。

   ```html
   <a href="#">链接文本</a>
   ```

4. 下载链接：如果地址指向文件或压缩包，会下载该文件。

   ```html
   <a href="xxxx.zip">下载文件</a>
   ```

5. 网页元素链接：可以给图片、表格、音频、视频等元素添加链接。

   ```html
   <a href="xxxx"><img src="xxxx" alt=""></a>
   ```

6. 锚点链接：用于定位页面中的位置。先给跳转目标设置 `id` 属性，再在链接中使用该 `id`。

   ```html
   <a href="#id">文本</a>
   ```

## 图像标签

```html
<img src="" alt="">
```

`src` 是 `img` 标签的必需属性，用于指定图像文件的路径和文件名。

图像标签的其他属性：

- `alt`：替换文本。
- `height` 或 `width`：只改变其中一个可以实现等比例缩放。
- `title="鼠标悬停于图片上出现的文字"`。
- `align="top"` 或 `align="bottom"`。

## 列表标签

表格标签用于呈现数据，列表标签用于页面布局。列表可以嵌套使用。

### 无序列表

没有顺序的并列内容使用无序列表（unordered list）。

`ul` 标签中只能直接嵌套 `li` 标签，不能直接包含其他标签或文字；`li` 标签相当于一个容器，可以容纳各种元素。

```html
<ul>
  <li></li>
  <li></li>
</ul>
```

无序列表自带样式，也可以通过 CSS 设置。原笔记中记录的列表样式写法：

```html
<ul type="square"></ul>
<ul type="circle"></ul>
<ul type="disc"></ul>
```

### 有序列表

有顺序的排列内容使用有序列表（ordered list），注意点与无序列表相同。

```html
<ol>
  <li></li>
  <li></li>
</ol>
```

### 自定义列表

自定义列表（definition list）常用于对术语或名词进行解释、描述或拓展，列表项前没有项目符号。

```html
<dl>
  <dt></dt>
  <dd></dd>
  <dt></dt>
  <dd></dd>
</dl>
```

## 表格标签

```html
<table>
  <tr>
    <th>列标题1</th>
    <th>列标题2</th>
  </tr>
  <tr>
    <td>元素1</td>
    <td>元素2</td>
  </tr>
</table>
```

每个 `tr` 表示单独的一行。

给表格添加边框：

```html
<table border="1"></table>
```

## 表单标签

表单用于与用户交互并收集用户信息，主要由表单域、表单控件和提示信息组成。

### 表单域

`form` 标签定义包含所有表单元素的区域，并把范围内的表单数据提交给服务器。`action` 属性用于指定提交地址；没有实际地址时可以暂时使用 `#` 占位。

```html
<form action="#">
  <!-- 表单控件 -->
</form>
```

### `input` 控件

`input` 是单标签，必要属性为 `type`。

```html
<input type="text">
```

常见类型：

- `type="text"`：输入文本。
- `type="radio"`：单选圆点。
- `type="checkbox"`：复选框。
- `type="password"`：输入密码，内容不明文显示。
- `type="submit"`：提交按钮，可以使用 `value` 改变按钮文本。

其他常见属性：

- `placeholder`：在文本框中显示提示内容。
- `value`：设置文本框中的初始内容或提交值。
- `name` 和 `value`：表单控件提交给后台时使用的常见属性。
- `checked`：用于设置单选按钮或复选框的默认选中状态。

同一组单选按钮使用相同的 `name`，从而实现组内单选；复选框是否共用 `name` 取决于提交数据的组织方式。

### `label` 标签

`label` 用于绑定表单元素。点击标签中的文本时，浏览器会把焦点移到或选中对应的表单控件，从而扩大可点击区域。

```html
<label for="sex">男</label>
<input type="radio" name="sex" id="sex">
```

`label` 的 `for` 属性与相关控件的 `id` 属性相对应。

### `textarea` 文本域

输入内容较多或需要换行时，使用文本域而不是单行文本框。

- `cols`：每行中的字符数。
- `rows`：显示的行数。

实际开发中通常使用 CSS 调整文本域大小。
