# HTML 常用标签

## `div` 与 `span` 标签

`div` 和 `span` 标签没有语义，主要作为盒子组织内容。

- `div`：`division`，表示分区，是用于组织内容的块级标签。它可以看作大盒子，一行只能放一个 `div`。
- `span`：表示跨度、跨距，用于包装一小部分文本，以便使用 CSS、JavaScript 等工具处理；它可以看作小盒子，可以横向显示多个 `span`。

表格 `table` 本身可以看作大盒子，其中的 `td`、`th` 是一个个小盒子。

### `div` 标签

`div` 后面可以添加 `class`、`id` 等属性：

```html
<div class="类名"></div>
```

Emmet 快捷写法：

- 带 `class` 的 `div`：输入 `.类名` 或 `div.类名` 后按 `Tab` 键。
- 带 `id` 的 `div`：输入 `#id名` 或 `div#id名` 后按 `Tab` 键。

### `span` 标签

```html
<span>文本内容</span>
```

## 链接标签

链接可以分为以下几种：

1. 外部链接。
2. 内部链接。
3. 空链接。

   ```html
   <a href="#">链接文本</a>
   ```

4. 下载链接：如果地址指向文件或压缩包，会下载该文件。

   ```html
   <a href="xxxx.zip">下载文件</a>
   ```

5. 网页元素链接：可以给图片、表格、音频、视频等元素添加链接。

   ```html
   <a href="xxxx"><img src="xxxx" alt=""></a>
   ```

6. 锚点链接：用于定位页面中的位置。先给跳转目标设置 `id` 属性，再在链接中使用该 `id`。

   ```html
   <a href="#id">文本</a>
   ```

## 图像标签

```html
<img src="" alt="">
```

`src` 是 `img` 标签的必需属性，用于指定图像文件的路径和文件名。

图像标签的其他属性：

- `alt`：替换文本。
- `height` 或 `width`：只改变其中一个可以实现等比例缩放。
- `title="鼠标悬停于图片上出现的文字"`。
- `align="top"` 或 `align="bottom"`。
