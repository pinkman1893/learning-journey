# Web 与 HTML 基础

## Web 标准

Web 标准由结构（structure）、表现（presentation）和行为（behavior）三方面构成：

- 结构：对网页元素进行整理和分类，现阶段主要使用 HTML。
- 表现：设置网页元素的版式、颜色、大小等外观样式，主要使用 CSS。
- 行为：定义网页模型并编写交互，现阶段主要使用 JavaScript。

相比较而言，结构是最重要的。

Web 标准提出的最佳体验方案是让结构、样式和行为相分离。

## 单标签与双标签

### 单标签

用于没有内容的元素。

### 双标签

包含内容的元素。

## HTML 文档结构

### `<!DOCTYPE html>`

`DOCTYPE` 是文档类型声明，用于告诉浏览器使用哪种 HTML 版本显示文档。它应位于 HTML 根元素之前，也就是文档的最开头。

在 VS Code 中输入英文感叹号后按回车键或 `Tab` 键，可以生成 HTML 文档结构。

### `<html></html>`

`html` 是整个 HTML 文档的根元素，也是文档的起始点和终止点。

#### `lang` 属性

`lang` 属性用于定义文档显示的语言：

1. `en` 表示英语。
2. `zh-CN` 表示中文。

即使定义为 `en` 也可以显示中文，定义为 `zh-CN` 也可以显示英文；这个属性主要为浏览器和辅助工具提供语言提示。

```html
<html lang="en">
```

### `<head></head>`

文档头部包含元信息，例如文档标题、字符编码、外部样式表以及脚本等。

原笔记强调在 `head` 元素中设置 `title` 元素。

#### 字符集

字符集声明便于计算机识别和存储各种文字。

```html
<meta charset="UTF-8">
```

UTF-8 是一种支持多种语言字符的编码方式。

### `<title></title>`

用于设置文档标题。

### `<body></body>`

用于放置实际在浏览器中显示的内容，例如文本、图像和链接。

## 快捷键

在 VS Code 中，可以使用 `Ctrl + /` 快速添加或取消注释。
