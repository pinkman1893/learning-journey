# 模型推理参数配置

推理参数不同于**训练参数**，它们在**推理过程**中被调用，影响模型在推理期间的输出。具体参数包括 Completion 中的最大 Token 数量、输出内容创造性等方面。

## Max New Tokens（最大生成 Token 数量）

- 限制模型生成的最大 Token 数量。

## Greedy 与 Random Sampling

- **Greedy（贪婪解码）**：模型对于 Softmax Layer 产生的所有词汇概率分数，直接选择最高概率的单词。Greedy 对于短期生成效果很好，但易于产生重复词语或词语序列。想要生成更自然、更具有创造性的输出，需要其他解码控制手段。
- **Random Sampling（随机采样）**：模型对于 Softmax Layer 产生的所有词汇概率分数，按照概率分布的权重随机选择一个输出词。Random Sampling 降低了词汇重复的可能性，但加大了 Completion 没有逻辑的可能性。

## Top-k 与 Top-p

- Top-k 和 Top-p 是 Random Sampling 的两个技术参数，可以限制随机采样，提高输出有逻辑、有意义的可能性。
- **Top-k**：限制模型只从概率最高的 k 个 Token 中进行选择。
- **Top-p**：按概率从高到低排序，选择累计概率达到阈值 p 的最小 Token 集合，再从中采样。

## Temperature

- **作用**：影响模型计算下一个 Token 的概率分布，用于控制输出的随机性。
- **影响**：Temperature 越高，概率分布越宽、越平，随机性越高。
- **原理**：Temperature 是 Softmax 输出层中的一个缩放因子，影响下一个 Token 的概率分布形状，默认值为 1。
- **注意**：Temperature、Top-k 和 Top-p 都会影响采样分布及最终输出。
