# 平衡二叉树的定义：
<font style="color:rgb(48, 48, 48);">如果一个树的</font>**<font style="color:rgb(48, 48, 48);">高度是节点数的对数级</font>**<font style="color:rgb(48, 48, 48);">（即 </font>_<font style="color:rgb(48, 48, 48);">O</font>_<font style="color:rgb(48, 48, 48);">(log</font>_<font style="color:rgb(48, 48, 48);">n</font>_<font style="color:rgb(48, 48, 48);">)），那么它就是</font>**<font style="color:rgb(48, 48, 48);">平衡的</font>**

# <font style="color:rgb(48, 48, 48);">AVL 树的定义</font>
AVL 树首先是一棵二叉搜索树，要么为空，要么满足以下条件

+ 左右子树的高度差的绝对值小于等于 1
+ 左右子树都是 AVL 树

AVL 树的树高和节点成对数关系

## 平衡因子 Balance Factor
$ 平衡因子 = 左子树高度 - 右子树高度 $

$ Balance\ Factor(node)  = Height(LeftSubtree) - Height(RightSubtree) $

+ 若任意节点的平衡因子的绝对值大于 1，则当前二叉搜索树失衡，需要通过旋转调整平衡

# 平衡二叉树的性质：
由于严格的平衡限制，平衡二叉树的高都为 Log(n)

> 题型：
>
> 1. 给定高度 h，构建一棵平衡二叉树最少需要几个节点
>
> **递推公式**：
>
> + $ min_0 = 1 $
> + $ min_1 = 2 $
> + $ min_h = min_{h-1} + min_{h-2} + 1 $ (对于 $ h \ge 2 $)
>
> **通项公式**：
>
> + $ min_h = fib(h + 3) - 1 $
> 2. 给定高度 h，构建一棵平衡二叉树最多能包含几个节点
> + 即为满二叉树，$ max_h = 2^{h + 1} -1 $
>
>
>
> 3. 对于给定元素个数，构建平衡二叉树的最大高度为多少
>
> **根据以上 **$ min_h $**公式夹一个 h 出来**
>
> 4. 证明 AVL 树高度保持在 O(logn)级别
> + $ n \ge min_h = fib(h + 3) - 1 \ge {(\frac{3}{2})}^h $
> + $ h \le \log_{1.5} n $
>



# 树的旋转(rotation)：
> 旋转操作的执行时间都为常数时间
>

目的：将失衡的二叉搜索树变得平衡

## 树的右旋
右旋节点变成原左孩子的右孩子

原左孩子的右孩子变成右旋节点的左孩子

**简记：右旋就是向右旋转，冲突的右孩变左孩**

## 树的左旋
左转节点成为原右孩子的左孩子

原右孩子的左孩子变成左转节点的右孩子

**简记：左旋就是向左旋转，冲突的左孩变右孩**

# 树的四种失衡情况和对策
> 判断失衡情况的一种方式：直接看插入位置在失衡节点的什么位置；在失衡节点左孩子的右子树上——>LR 型失衡；也可以判断平衡因子，如下：

## LL 型失衡：
+ 特征：失衡节点的平衡因子为 2，失衡节点左孩子平衡因子为 1
+ 对策：对失衡节点进行右旋

![](assets/246042641/028823ce0ec1.png)             ![](assets/246042641/8a3879ca9cfa.png)

```cpp
//x 为失衡点， y为失衡点的左孩子
x->left = y->right;
y->right = x;
// 需同时更新 x, y 以及 x->parent 的父指针关系
```

## RR 型失衡
+ 特征：失衡节点的平衡因子为 -2，失衡节点右孩子平衡因子为 -1
+ 对策：对失衡节点进行左旋

![](assets/246042641/f54791c3771a.png)          ![](assets/246042641/4b48c77e30ad.png)

## LR 型失衡
+ 特征：失衡节点的平衡因子为 2，失衡节点左孩子平衡因子为 -1
+ 对策：先左旋失衡节点的左孩子，失衡节点再右旋

![](assets/246042641/452cab1cb24c.png)     ![](assets/246042641/fe44c270e7f3.png)

+ 对策：先右旋失衡节点的右孩子，失衡节点再左旋
