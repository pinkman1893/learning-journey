# 第二章：递归与分治

## 递归的概念

### 递归算法与递归函数

- 递归算法：直接或间接调用自身的算法。
- 递归函数：用函数自身给出定义的函数。

### 递归的基本思想

- 基于归纳法的递归：应用数学归纳法的思想，由基础步（基础解）和归纳步（由小规模问题的解推出大规模问题的解）构成。
- 基于分治法的递归：把问题划分成一个或多个子问题来递归求解。

#### 归纳法的思想

![归纳法的思想](assets/285493670/fc9386555343.png)

#### 分治法的思想

> 将一个难以直接解决的大问题，分割成一些规模较小的相同问题，以便各个击破，分而治之。

### 递归和分治的关系

由分治法产生的子问题往往是原问题的较小模式，通过反复应用分治手段，使子问题与原问题类型一致而规模不断缩小，最终降至能直接求解，这自然导致了递归过程。两者像一对孪生兄弟，常结合使用。

### 递归函数的二要素

递归函数必须具备以下两个要素，才能保证在有限次计算后给出结果：

1. **边界条件（Base Case）**：确定递归终止的条件与初始解。
2. **递归方程（Recurrence Equation）**：将原问题转化为较小规模同类问题的递推表达式。

## 递归算法的优缺点

- **优点**：结构清晰、可读性强、易于用数学归纳法证明正确性。
- **缺点**：运行效率较低，耗费的计算时间和存储空间均多于非递归算法。
- **解决方案**：转换为递推或者尾递归，消除递归。

## 分治法的概念

### 分治法的总体思想

分治法（Divide-and-Conquer）的设计思想是将一个难以直接解决的大问题 $P(n)$，分割成 $k$ 个规模较小、互相独立、结构与原问题相同的子问题。递归地求解这些子问题，直到规模小至阈值 $n_0$ 可以直接求解，再将子问题的解合并为原问题的解。

### 分治法适用的四个基本条件

- 该问题的规模缩小到一定的程度就可以容易地解决。
- 该问题可以分解为若干个规模较小的相同问题。
- 分解出的子问题的解可以合并为原问题的解。
- 分解出的各个子问题是相互独立的。

### 分治法设计的基本步骤

1. 先定义阈值 $`n_0`$，解决小规模的问题。
2. **划分步（Divide）**：将输入问题划分为 $`k`$ 个子问题。
3. **治理步（Conquer）**：当规模大于阈值 $`n_0`$ 时递归调用，小于等于 $`n_0`$ 时直接求解。
4. **组合步（Combine / Merge）**：将子问题的解组合为原问题的解。

![分治法设计的基本步骤](assets/285493670/651ad64c5bdb.png)

### 平衡子问题思想

> 在划分问题时，尽量使 $k$ 个子问题的规模大致相同，这种平分做法几乎总是比子问题规模不等的做法性能更好。

### 分治法的复杂度分析

设分解阈值 $n_0=1$，将规模为 $n$ 的问题划分为 $k$ 个规模为 $n/m$ 的子问题，分解与合并耗时 $f(n)$，则复杂性方程为：

$$
T(n)=
\begin{cases}
O(1), & n=1 \\
kT(n/m)+f(n), & n>1
\end{cases}
$$

## 经典分治算法示例

### 二分搜索技术

![二分搜索技术](assets/285493670/618c2d81e9f4.png)

```java
public static int binarySearch(int[] a, int x, int n)
{
    // 在 a[0] <= a[1] <= ... <= a[n-1] 中搜索 x
    // 找到 x 时返回其在数组中的位置，否则返回 -1
    int left = 0;
    int right = n - 1;
    while (left <= right) {
        int middle = (left + right) / 2;
        if (x == a[middle]) return middle;
        if (x > a[middle]) left = middle + 1;
        else right = middle - 1;
    }
    return -1; // 未找到 x
}
```

- **算法复杂度分析**：每执行一次算法的 `while` 循环，待搜索数组的大小减少一半。因此在最坏情况下，`while` 循环被执行了 $`O(\log n)`$ 次。循环体内运算需要 $`O(1)`$ 时间，因此整个算法在最坏情况下的计算时间复杂度为 $`O(\log n)`$。

### 合并排序（Merge Sort）

![合并排序的分治过程](assets/285493670/2159360ea859.png)

复杂度为：$\boxed{T(n)=2T(n/2)+\Theta(n)}$。

```cpp
void MergeSort(Type a[], int left, int right)
{
    if (left < right) { // 至少有 2 个元素
        int i = (left + right) / 2; // 取中点
        MergeSort(a, left, i);
        MergeSort(a, i + 1, right);
        merge(a, b, left, i, right); // 合并到数组 b
        copy(a, b, left, right);     // 复制回数组 a
    }
}
```

### 快速排序（Quick Sort）

![快速排序的分治思想](assets/285493670/f8204305e4e4.png)

![快速排序的复杂度](assets/285493670/7578e2c01ae2.png)

```cpp
template<class Type>
void QuickSort(Type a[], int p, int r)
{
    if (p < r) {
        int q = Partition(a, p, r);
        QuickSort(a, p, q - 1); // 对左半段排序
        QuickSort(a, q + 1, r); // 对右半段排序
    }
}

template<class Type>
int Partition(Type a[], int p, int r)
{
    int i = p, j = r + 1;
    Type x = a[p];
    // 将 < x 的元素交换到左边区域
    // 将 > x 的元素交换到右边区域
    while (true) {
        while (a[++i] < x);
        while (a[--j] > x);
        if (i >= j) break;
        Swap(a[i], a[j]);
    }
    a[p] = a[j];
    a[j] = x;
    return j;
}
```

#### 如何选择划分基准

1. 按照五个元素一组，将全部元素划分成各组，最后一组可能不足 5 个元素。
2. 取各组中位数，中位数再组合成一组。
3. 再递归地取中位数，最终最后唯一一个中位数即为划分基准。

### 最接近点对问题（Closest Pair of Points）

- 题目背景：平面上有 $`n`$ 个点，找出距离最近的两个点。

#### 一维情形

用中位数 $m$ 将点集划分为 $S_1,S_2$，递归求得左右最小距离 $d=\min(d_1,d_2)$。跨越分割线的点对只需要检查 $(m-d,m]$ 和 $(m,m+d]$ 区域，线性时间合并。

![最接近点对问题的一维情形](assets/285493670/3dedab090d54.png)

#### 二维情形

用 x 轴坐标中位数 $x=m$ 将点集划分为 $S_1,S_2$，递归求得左右最小距离 $d=\min(d_1,d_2)$。跨越分割线的点对只需要检查条带 $(m-d,m]$ 和 $(m,m+d]$ 区域的全部点，对于这些点再按 y 轴坐标排序，从下往上对于每个点，找 y 轴坐标差值在 $d$ 内的两个点参加比较，线性时间合并。

![最接近点对问题的二维划分](assets/285493670/0ac6b85839d5.png)

![最接近点对问题的线性合并](assets/285493670/aff10d46d052.png)

- 复杂度递归式：$`T(n)=2T(n/2)+O(n)`$，最终 $`T(n)=O(n\log n)`$。
