# 从 C语言到 C++ 的基础语法过渡

## 基本输入输出示例

```cpp
#include <iostream>

using namespace std;

int main()
{
    int n;
    cin >> n;
    cout << "FUCK!" << n++ << endl;
    return 0;
}
```

这段代码使用 `std::cin` 读取整数，通过 `std::cout` 输出文本和变量，并展示了后缀自增 `n++`。

## C++ 头文件

`<iostream>` 是标准输入输出流头文件，提供 `std::cin`、`std::cout` 和 `std::endl` 等组件。

```cpp
#include <iostream>
```

C++ 标准库通常使用不带 `.h` 的头文件名称。部分 C标准库头文件在 C++ 中有以 `c` 开头的对应版本：

```cpp
#include <cmath>
#include <cstring>
```

例如 `<cmath>` 对应 C语言的 `<math.h>`，`<cstring>` 对应 `<string.h>`。C++ 版本通常把相关名称放在 `std` 命名空间中。

## `std` 命名空间

C++ 标准库组件定义在 `std` 命名空间中。使用时可以写出完整名称：

```cpp
std::cout << "Hello" << '\n';
```

也可以通过 `using namespace std;` 在当前作用域省略 `std::` 前缀：

```cpp
using namespace std;
cout << "Hello" << '\n';
```

在较大的项目和头文件中，显式使用 `std::` 更容易避免不同命名空间之间的名称冲突。

## `cin` 与 `cout`

- `std::cin >> value`：从标准输入读取数据。
- `std::cout << value`：向标准输出写入数据。

它们分别承担与 `scanf`、`printf` 类似的输入输出功能，但接口形式不同。默认配置下，C++ 流式输入输出在某些高强度场景中可能慢于 C标准输入输出。需要提高速度时，可以在不混用两套接口的前提下关闭同步：

```cpp
std::ios::sync_with_stdio(false);
std::cin.tie(nullptr);
```

## `std::endl` 与换行符

`std::endl` 会写入换行并立即刷新输出缓冲区：

```cpp
std::cout << "Hello" << std::endl;
```

如果不需要立即刷新，通常使用 `\n`：

```cpp
std::cout << "Hello\n";
```

## 前缀自增与后缀自增

- `n++`：先产生自增前的值，再让 `n` 加一。
- `++n`：先让 `n` 加一，再产生自增后的值。

```cpp
int n = 10;
std::cout << n++ << '\n';  // 输出 10，之后 n 变为 11
std::cout << ++n << '\n';  // n 先变为 12，再输出 12
```

## 使用 `const` 定义不可修改的对象

在变量声明中加入 `const`，表示初始化后不能再通过该变量修改其值。

```cpp
const int max_value = 150;
```

`const` 对象必须在使用前完成初始化。

## `std::string` 字符串

`std::string` 定义在 `<string>` 头文件中，比 C风格字符数组更便于完成复制、拼接和长度管理。

### 定义与拼接

```cpp
#include <string>

std::string s1 = "FUCK YOU,";
std::string s2 = "WDNMD";
std::string result = s1 + s2;
```

### 使用 `getline` 读取一行

`operator>>` 读取字符串时会在空白字符处停止，`std::getline` 则读取到换行符为止，并把换行符从输入流中取走但不存入字符串。

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string line;
    std::getline(std::cin, line);
    std::cout << line << '\n';
    return 0;
}
```

如果先使用 `std::cin >> value`，再调用 `std::getline`，输入流中可能残留换行符。可以先忽略到行尾：

```cpp
#include <limits>

std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
std::getline(std::cin, line);
```

### 获取长度

`size()` 和 `length()` 都返回字符串包含的元素数量：

```cpp
std::cout << result.size() << '\n';
std::cout << result.length() << '\n';
```

对于 UTF-8 字符串，该数量是编码单元的字节数，并不一定等于用户看到的字符数量。

### 获取子串

```cpp
std::string text = "Hello, C++";

std::string first = text.substr(0, 5);  // 从索引 0 开始取 5 个元素
std::string rest = text.substr(7);      // 从索引 7 一直取到末尾
```

若起始位置超过字符串长度，`substr` 会抛出 `std::out_of_range`。

## C++ 中的结构体

结构体的定义方式与 C语言相近。在 C++ 中定义结构体变量时，可以直接使用结构体名称，不需要再次书写 `struct`。

```cpp
#include <iostream>
#include <string>

struct Student
{
    std::string name;
    int age;
};

int main()
{
    Student student{"小明", 18};

    std::cout << "姓名：" << student.name << '\n';
    std::cout << "年龄：" << student.age << '\n';
    return 0;
}
```

## 获取对象或容器的大小

`std::string` 和许多标准库容器提供 `.size()` 成员函数：

```cpp
std::string text = "hello";
std::cout << text.size() << '\n';
```

并非所有变量都支持 `.size()`。普通对象的字节大小使用 `sizeof`；内置数组的元素数量可以使用 C++17 的 `std::size`：

```cpp
#include <iterator>

int numbers[] = {1, 2, 3, 4};
std::cout << std::size(numbers) << '\n';
```
