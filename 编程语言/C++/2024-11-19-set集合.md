# C++ set 集合

`std::set` 是标准库中的有序关联容器，用于保存不重复的键。使用前需要包含 `<set>`。

```cpp
#include <set>
```

## set 与 vector 的选择

- 需要元素唯一、按比较规则保持有序，并经常按值查找时，可以使用 `set`。
- 需要连续存储、按索引随机访问，或主要在末尾添加和删除元素时，可以使用 `vector`。

`set` 不提供下标访问；`vector` 也不会自动去重或排序。

## 主要特性

1. 每个键只保存一份，重复插入不会增加新元素。
2. 元素按照比较器确定的顺序排列，默认比较器是 `std::less<Key>`。
3. 插入、查找和删除按键定位，通常具有对数复杂度。
4. 元素不能通过迭代器直接修改，以免破坏容器的排序规则。

## 创建 set

### 创建空集合

```cpp
std::set<int> values;
```

### 使用列表初始化

```cpp
std::set<int> values{2, 5, 8, 8, 9};
```

初始化完成后只会保留一个 `8`。

`set` 不像 `vector` 那样支持“创建指定数量的元素”或“创建若干个相同元素”的构造方式，因为它是按键组织的关联容器，并且键必须唯一。

## 插入元素

### 插入单个元素

```cpp
values.insert(1);
```

单元素 `insert` 返回一个二元组：迭代器指向对应元素，布尔值表示是否发生了新插入。

```cpp
auto [iterator, inserted] = values.insert(5);

if (!inserted) {
    std::cout << "元素已经存在\n";
}
```

结构化绑定需要 C++17。

### 插入多个元素

```cpp
values.insert({3, 5, 7, 9});
```

已经存在的键会被忽略。

## 遍历 set

可以使用迭代器遍历：

```cpp
#include <iostream>
#include <set>

int main()
{
    std::set<int> values{5, 1, 9, 3};

    for (auto iterator = values.begin(); iterator != values.end(); ++iterator) {
        std::cout << *iterator << ' ';
    }
    std::cout << '\n';

    return 0;
}
```

默认情况下输出顺序为 `1 3 5 9`。也可以使用范围 `for`：

```cpp
for (const int value : values) {
    std::cout << value << ' ';
}
```

## 查找元素

`find` 返回迭代器，而不是原始内存地址。找到时迭代器指向对应元素，未找到时等于 `end()`。

```cpp
auto iterator = values.find(5);

if (iterator != values.end()) {
    std::cout << "找到了：" << *iterator << '\n';
}
```

C++20 可以使用 `contains` 直接判断键是否存在：

```cpp
if (values.contains(5)) {
    std::cout << "元素存在\n";
}
```

## 获取元素数量与判空

```cpp
std::cout << values.size() << '\n';

if (values.empty()) {
    std::cout << "集合为空\n";
}
```

- `size()` 返回元素数量。
- `empty()` 返回布尔值，表示集合是否为空。

## 删除元素

### 按值删除

```cpp
std::size_t removed = values.erase(5);
```

由于 `set` 中键唯一，返回值只能是 `0` 或 `1`，表示删除的元素数量。

### 按迭代器删除

```cpp
auto iterator = values.find(5);

if (iterator != values.end()) {
    values.erase(iterator);
}
```

删除某个元素只会使指向该元素的迭代器和引用失效，其他元素的迭代器仍然有效。

## 自定义排序规则

默认 `set` 使用升序比较。可以通过比较器改变顺序：

```cpp
#include <functional>
#include <set>

std::set<int, std::greater<int>> values{2, 5, 8, 9};
```

此时遍历结果按降序排列。比较器必须满足严格弱序要求，否则容器行为不正确。

## 本节函数小结

- `insert()`
- `find()`、`contains()`（C++20）
- `erase()`
- `size()`、`empty()`
- `begin()`、`end()`
