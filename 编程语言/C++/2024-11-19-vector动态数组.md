# C++ vector 动态数组

`std::vector` 是标准库提供的动态顺序容器，元素连续存储，可以在运行时调整元素数量。使用前需要包含 `<vector>`。

```cpp
#include <vector>
```

## 创建 vector

### 创建空容器

```cpp
std::vector<int> values;
```

### 创建指定数量的元素

```cpp
std::vector<int> values(10);
```

这里创建 10 个 `int` 元素，并对它们进行值初始化，因此元素值均为 `0`。

### 指定元素数量和初始值

```cpp
std::vector<int> values(10, 2);
```

容器包含 10 个元素，每个元素的初始值都是 `2`。

### 使用列表初始化

```cpp
std::vector<int> values{1, 2, 3, 4, 5};
```

## 大小与容量

- `size()`：当前实际包含的元素数量。
- `capacity()`：无需重新分配内存时最多可以容纳的元素数量。
- `empty()`：判断容器是否为空。

```cpp
std::cout << values.size() << '\n';
std::cout << values.capacity() << '\n';
```

### `resize`

`resize` 改变元素数量：

```cpp
values.resize(10);
```

- 扩大时会在末尾添加新元素，新增的 `int` 会被值初始化为 `0`。
- 缩小时会删除超出新大小范围的元素。

也可以为新增元素指定值：

```cpp
values.resize(20, -1);
```

### `reserve`

`reserve` 预留容量，但不会改变现有元素数量：

```cpp
values.reserve(100);
```

已知后续会添加大量元素时，提前预留容量可以减少重新分配次数。

## 添加元素

`push_back` 在末尾添加单个元素，并让 `size()` 增加一：

```cpp
values.push_back(114514);
```

当现有容量不足时，`vector` 会申请更大的连续存储空间并移动或复制原有元素。容量具体增长多少由实现决定，不能假设一定翻倍。

## 访问元素

### 使用下标

```cpp
int value = values[2];
```

`operator[]` 不进行边界检查，索引越界会导致未定义行为。

### 使用 `at`

```cpp
int value = values.at(2);
```

`at` 会检查索引。越界时抛出 `std::out_of_range` 异常，适合索引来源不确定、需要明确错误处理的场景。

## 删除和清空元素

### 删除末尾元素

```cpp
values.pop_back();
```

调用前必须确保容器非空。

### 删除指定位置

`erase` 接受迭代器而不是整数索引：

```cpp
std::size_t index = 2;
if (index < values.size()) {
    values.erase(values.begin() + index);
}
```

删除后，被删除位置及其后的迭代器和引用会失效。

### 清空容器

```cpp
values.clear();
```

`clear` 删除全部元素，使 `size()` 变为 `0`，但通常不会减少 `capacity()`。

## 迭代器

迭代器提供统一的容器元素访问接口，用法与指针相似，但它是更高层次的抽象。`vector` 的迭代器支持随机访问。

- `begin()`：指向第一个元素。
- `end()`：指向最后一个元素之后的位置，不能解引用。

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> values(10);

    for (int i = 0; i < 10; ++i) {
        values[i] = i + 1;
    }

    values.push_back(11);

    for (auto iterator = values.begin(); iterator != values.end(); ++iterator) {
        std::cout << *iterator << ' ';
    }
    std::cout << '\n';

    return 0;
}
```

只需要读取元素时，可以使用 `const_iterator`：

```cpp
for (auto iterator = values.cbegin(); iterator != values.cend(); ++iterator) {
    std::cout << *iterator << ' ';
}
```

也可以使用范围 `for` 循环：

```cpp
for (const int value : values) {
    std::cout << value << ' ';
}
```

对通用迭代器通常优先使用前缀 `++iterator`，因为它不需要保留递增前的旧值；具体能否产生性能差异取决于迭代器类型和编译器优化。

## 内存重新分配与失效规则

`vector` 的元素连续存储。当新增元素导致容量不足时，容器会重新分配空间，此前指向元素的全部指针、引用和迭代器都会失效。

未发生重新分配时，不同修改操作仍有各自的失效规则。例如 `erase` 会使删除位置及其后的迭代器失效。因此，在修改容器后继续使用旧迭代器前，需要确认对应操作的失效规则。

## 本节函数小结

- `size()`、`capacity()`、`empty()`
- `resize()`、`reserve()`
- `push_back()`、`pop_back()`
- `operator[]`、`at()`
- `erase()`、`clear()`
- `begin()`、`end()`、`cbegin()`、`cend()`
