# 为何学习 C++

## 编程语言的四类需求

选择编程语言时，通常需要考虑四个方面：

- **效率（efficiency）**：程序对计算资源的利用与运行性能。
- **灵活性（flexibility）**：语言对底层控制和不同编程方式的支持程度。
- **抽象能力（abstraction）**：隐藏实现细节、组织复杂系统的能力。
- **生产力（productivity）**：开发者编写、维护和交付软件的效率。

## C++ 的特点

C语言侧重运行效率和底层控制；Java、.NET 等平台更强调抽象能力和开发生产力。

C++ 在保留较强性能和灵活性的同时，提供了面向对象、泛型编程和标准库等抽象工具，适用范围也较广。这种兼顾底层控制与高层抽象的特点，是学习 C++ 的主要原因。
