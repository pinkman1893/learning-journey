# C++ map 映射

`std::map` 是保存键值对的有序关联容器。每个键都是唯一的，一个键对应一个值；不同键可以对应相同的值。

使用前需要包含 `<map>`：

```cpp
#include <map>
```

## 键值对

键值对由两部分组成：

- **键（key）**：唯一标识一个元素，用于查找、排序和删除。
- **值（value）**：与键关联的数据，类型可以与键不同，也可以在不同元素之间重复。

`map` 默认使用 `std::less<Key>` 对键进行排序。字符串键通常按字典序比较，但不应简单概括为“按 ASCII 码排序”，因为实际比较取决于键类型及其比较器。

## 创建 map

```cpp
#include <map>
#include <string>

std::map<std::string, int> scores;
```

这里键的类型是 `std::string`，值的类型是 `int`。

也可以使用列表初始化：

```cpp
std::map<std::string, int> scores{
    {"alice", 90},
    {"bob", 85}
};
```

## 插入和更新元素

### 使用 `operator[]`

```cpp
scores["pinkman"] = 1;
```

- 键不存在时，`operator[]` 会先插入该键和值类型的默认值，再进行赋值。
- 键已经存在时，会修改对应的值。

因此，只想查询而不希望意外插入元素时，不应使用 `operator[]`。

### 使用 `insert`

```cpp
scores.insert({"pinkman", 1});
```

键已经存在时，`insert` 不会更新原值。返回结果中包含对应元素的迭代器和表示是否成功插入的布尔值。

```cpp
auto [iterator, inserted] = scores.insert({"pinkman", 1});

if (!inserted) {
    std::cout << "键已经存在\n";
}
```

结构化绑定需要 C++17。

### 插入或更新

C++17 可以使用 `insert_or_assign` 明确表达“键不存在则插入，存在则更新”：

```cpp
scores.insert_or_assign("pinkman", 100);
```

## 查找元素

`find` 根据键查找元素。找到时返回指向键值对的迭代器，未找到时返回 `end()`。

```cpp
#include <iostream>
#include <map>
#include <string>

int main()
{
    std::map<int, std::string> fruits{
        {1, "apple"},
        {2, "banana"}
    };

    int number;
    std::cout << "请输入水果序号：";
    std::cin >> number;

    auto iterator = fruits.find(number);

    if (iterator != fruits.end()) {
        std::cout << number << " 对应：" << iterator->second << '\n';
    } else {
        std::cout << "没有找到\n";
    }

    return 0;
}
```

迭代器指向的元素类似 `std::pair<const Key, Value>`：

- `iterator->first`：键。
- `iterator->second`：值。

C++20 可以使用 `contains` 判断键是否存在：

```cpp
if (scores.contains("pinkman")) {
    std::cout << "键存在\n";
}
```

## 通过键访问值

键确定存在且允许插入默认值时，可以使用 `operator[]`：

```cpp
std::cout << scores["pinkman"] << '\n';
```

只想读取已有键时，可以使用 `at`。键不存在时会抛出 `std::out_of_range`：

```cpp
std::cout << scores.at("pinkman") << '\n';
```

需要自行处理“键不存在”的情况时，使用 `find` 更合适。

## 删除元素

### 按键删除

```cpp
std::size_t removed = scores.erase("pinkman");
```

返回值表示删除的元素数量。由于 `map` 的键唯一，只可能是 `0` 或 `1`。

### 按迭代器删除

```cpp
auto iterator = scores.find("pinkman");

if (iterator != scores.end()) {
    scores.erase(iterator);
}
```

删除操作只会使指向被删除元素的迭代器和引用失效。

## 大小与判空

```cpp
std::cout << scores.size() << '\n';

if (scores.empty()) {
    std::cout << "map 为空\n";
}
```

- `size()` 返回键值对数量。
- `empty()` 判断容器是否为空。

## 遍历 map

使用迭代器遍历：

```cpp
for (auto iterator = scores.begin(); iterator != scores.end(); ++iterator) {
    std::cout << iterator->first << " : " << iterator->second << '\n';
}
```

C++17 可以使用结构化绑定：

```cpp
for (const auto &[key, value] : scores) {
    std::cout << key << " : " << value << '\n';
}
```

遍历顺序由键比较器决定，与元素的插入顺序无关。

## 本节函数和语法小结

- `operator[]`、`at()`
- `insert()`、`insert_or_assign()`
- `find()`、`contains()`（C++20）
- `erase()`
- `size()`、`empty()`
- `iterator->first`、`iterator->second`
