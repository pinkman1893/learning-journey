# C++ queue 队列

`std::queue` 是标准库中的容器适配器，用于实现先进先出（FIFO，First In, First Out）的队列。最先进入队列的元素最先被移除。

使用前需要包含 `<queue>`：

```cpp
#include <queue>
```

## 底层容器

`queue` 默认使用 `std::deque` 作为底层容器：

```cpp
std::queue<int> values;
```

也可以指定支持队首删除、队尾插入等必要操作的容器，例如 `std::list`：

```cpp
#include <list>
#include <queue>

std::queue<int, std::list<int>> values;
```

`queue` 不公开底层容器，也不提供迭代器或下标访问。

## 主要特性

- **先进先出**：从队尾加入，从队首移除。
- **受限访问**：只能直接访问队首和队尾元素。
- **封装操作**：不提供在中间位置插入、删除或遍历元素的接口。

## 入队

`push` 把元素加入队尾：

```cpp
values.push(10);
values.push(20);
values.push(30);
```

此时队首是 `10`，队尾是 `30`。

## 访问队首和队尾

### `front`

返回队首元素的引用：

```cpp
int first = values.front();
```

### `back`

返回队尾元素的引用：

```cpp
int last = values.back();
```

调用 `front` 或 `back` 前必须确保队列非空，否则行为未定义。

## 出队

`pop` 移除队首元素，但没有返回值：

```cpp
values.pop();
```

如果需要保存被移除的元素，应先访问 `front`：

```cpp
if (!values.empty()) {
    int removed = values.front();
    values.pop();
}
```

对空队列调用 `pop` 会导致未定义行为。

## 获取大小与判空

```cpp
std::cout << values.size() << '\n';

if (values.empty()) {
    std::cout << "队列为空\n";
}
```

- `size()`：返回当前元素数量。
- `empty()`：判断队列是否为空。

## 完整示例

```cpp
#include <iostream>
#include <queue>

int main()
{
    std::queue<int> values;

    values.push(10);
    values.push(20);
    values.push(30);

    std::cout << "队首：" << values.front() << '\n';
    std::cout << "队尾：" << values.back() << '\n';

    while (!values.empty()) {
        std::cout << values.front() << ' ';
        values.pop();
    }
    std::cout << '\n';

    return 0;
}
```

输出顺序为 `10 20 30`，体现了先进先出的规则。逐个输出会同时清空队列；若需要保留原队列，应先创建副本。

## 本节函数小结

- `push()`
- `front()`、`back()`
- `pop()`
- `size()`
- `empty()`
