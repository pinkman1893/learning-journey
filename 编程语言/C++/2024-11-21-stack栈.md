# C++ stack 栈

`std::stack` 是标准库中的容器适配器，提供后进先出（LIFO，Last In, First Out）的数据访问方式。元素只能从栈顶加入、访问和移除。

使用前需要包含 `<stack>`：

```cpp
#include <stack>
```

## 底层容器

`stack` 通过已有的顺序容器实现栈操作，默认底层容器是 `std::deque`。

```cpp
std::stack<int> values;
```

也可以明确指定满足要求的底层容器，例如 `std::vector`：

```cpp
#include <stack>
#include <vector>

std::stack<int, std::vector<int>> values;
```

## 主要特性

- **后进先出**：最后压入的元素最先移除。
- **只操作栈顶**：不能通过下标访问中间元素。
- **不提供迭代器**：没有 `begin()` 和 `end()`，不能直接遍历整个栈。

## 压栈

`push` 把元素加入栈顶：

```cpp
values.push(10);
values.push(20);
values.push(30);
```

此时栈顶元素是 `30`。

## 访问栈顶

`top` 返回栈顶元素的引用：

```cpp
int top_value = values.top();
values.top() = 100;
```

调用 `top` 前必须确保栈不为空，否则行为未定义。

## 出栈

`pop` 移除栈顶元素：

```cpp
values.pop();
```

`pop` 没有返回值。如果需要保存被移除的元素，应先调用 `top`，再调用 `pop`：

```cpp
if (!values.empty()) {
    int removed = values.top();
    values.pop();
}
```

对空栈调用 `pop` 会导致未定义行为。

## 获取大小与判空

```cpp
std::cout << values.size() << '\n';

if (values.empty()) {
    std::cout << "栈为空\n";
}
```

- `size()`：返回当前元素数量。
- `empty()`：判断栈是否为空。

## 完整示例

```cpp
#include <iostream>
#include <stack>

int main()
{
    std::stack<int> values;

    values.push(10);
    values.push(20);
    values.push(30);

    while (!values.empty()) {
        std::cout << values.top() << ' ';
        values.pop();
    }
    std::cout << '\n';

    return 0;
}
```

输出顺序为 `30 20 10`，体现了后进先出的规则。由于 `stack` 不提供迭代器，这种输出方式会逐个移除元素；若需要保留原栈，应先创建副本。

## 本节函数小结

- `push()`
- `top()`
- `pop()`
- `size()`
- `empty()`
