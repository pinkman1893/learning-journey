# C++ 输入输出流

## 使用 `cin.get()` 读取空白字符

普通的 `cin >>` 会跳过空白字符；需要连同空格一起读取时，可以使用 `cin.get()`：

```cpp
char a, b, c;
cin.get(a); // 此刻输入：n m，n 被提取进变量 a 中，空格和 m 保存在缓冲区中
cin.get(b); // 空格被提取进变量 b 中，m 仍在缓冲区
cin.get(c); // m 被提取进变量 c 中
cout << a << endl << b << endl << c << endl;

// 输出：
// n
//
// m
```
