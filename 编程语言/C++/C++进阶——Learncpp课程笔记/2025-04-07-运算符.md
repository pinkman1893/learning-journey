# C++ 运算符

## 赋值运算符

等号运算符 `=` 从右往左计算：

```cpp
x = y = z; // 等价于 x = (y = z);
```

## 三元运算符

- 三元运算符与输出运算符混用时，最好用括号包住整个三元表达式：

```cpp
cout << ((x > y) ? x : y);
```

- 三元运算符的两个分支应当是相同的数据类型，或者能够相互转换。
- 复杂的语句中不要使用三元运算符。

## 逻辑运算符优先级

`&&` 的优先级高于 `||`。
