# C语言字符串

## 字符串的存储方式

C语言没有独立的字符串类型。字符串以字符数组的形式存储，并使用空字符 `\0` 标记结尾。

```c
char text[4] = {'a', 'b', 'c', '\0'};
```

也可以简写为：

```c
char text[] = "abc";
```

字符串 `"abc"` 实际需要 4 个 `char` 的空间，其中最后一个位置用于保存 `\0`。

## 字符数组与字符串字面量

### 可修改的字符数组

```c
#include <stdio.h>

int main(void)
{
    char text[] = "abc";
    text[0] = 'A';
    printf("%s\n", text);
    return 0;
}
```

数组中保存的是字符串内容的副本，因此元素可以修改。

### 指向字符串字面量的指针

```c
const char *text = "abc";
```

此时指针指向字符串字面量。字符串字面量不能修改，因此应使用 `const char *` 表达这一约束。编译器是否合并内容相同的字符串字面量属于实现细节，程序不应依赖它们具有相同地址。

## 输入与遍历字符串

使用 `fgets` 可以限制输入长度，并允许读取空格。它可能将换行符一并读入，因此下面先使用 `strcspn` 去掉行尾换行。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[100];

    printf("请输入一行字符串：\n");
    if (fgets(text, sizeof(text), stdin) == NULL) {
        return 1;
    }

    text[strcspn(text, "\n")] = '\0';

    for (size_t i = 0; text[i] != '\0'; i++) {
        printf("%c ", text[i]);
    }
    printf("\n");

    return 0;
}
```

`scanf("%s", ...)` 遇到空白字符就会停止。如果只需要读取一个单词，也必须通过字段宽度防止越界，例如对 `char text[100]` 使用 `scanf("%99s", text)`。

## 字符串数组

长度固定的二维字符数组适合保存最大长度一致的多条字符串：

```c
char names[][16] = {
    "Alice",
    "Bob",
    "Carol"
};
```

如果字符串长度差异较大，也可以使用指针数组保存字符串字面量：

```c
#include <stdio.h>

int main(void)
{
    const char *names[] = {
        "张同学",
        "李同学",
        "王同学"
    };
    size_t count = sizeof(names) / sizeof(names[0]);

    for (size_t i = 0; i < count; i++) {
        printf("第%zu位学生是：%s\n", i + 1, names[i]);
    }

    return 0;
}
```

源码和终端常使用 UTF-8 编码。中文字符在 UTF-8 中通常占多个字节，因此不能假设“一个中文字符固定占两个字节”，`strlen` 得到的也是字节数而不是用户看到的字符数量。

## `<string.h>` 常用函数

使用字符串库函数前需要包含头文件：

```c
#include <string.h>
```

### `strlen`

返回字符串中 `\0` 之前的字节数，不包含结尾的空字符。

```c
size_t length = strlen(text);
```

### `strcpy`

把源字符串连同结尾的 `\0` 复制到目标数组。目标必须可写，并且空间足够大。

```c
char destination[20];
strcpy(destination, "hello");
```

### `strcat`

把源字符串追加到目标字符串末尾。目标必须已经以 `\0` 结尾、可以修改，并有足够的剩余空间。

```c
char destination[20] = "hello";
strcat(destination, " world");
```

### `strcmp`

按字节的无符号值逐个比较两个字符串：

- 返回 `0`：两个字符串相等。
- 返回负数：第一个字符串的字典序在第二个之前。
- 返回正数：第一个字符串的字典序在第二个之后。

```c
if (strcmp(left, right) == 0) {
    /* 两个字符串相等 */
}
```

`strlwr` 和 `strupr` 不是标准 C 函数，可移植程序不应依赖它们。处理英文大小写时，可以使用 `<ctype.h>` 中的 `tolower` 和 `toupper` 逐字符转换。

## 登录校验示例

下面使用明确的演示凭据说明字符串比较。真实程序不应在源码中保存明文密码，而应使用可靠的身份认证和密码哈希方案。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char username[] = "demo_user";
    const char expected_password[] = "example_password";
    char input_password[64];

    printf("Username: %s\n", username);

    for (int attempt = 1; attempt <= 3; attempt++) {
        printf("请输入演示密码：");

        if (scanf("%63s", input_password) != 1) {
            return 1;
        }

        if (strcmp(expected_password, input_password) == 0) {
            printf("验证成功\n");
            return 0;
        }

        printf("验证失败，还可尝试 %d 次\n", 3 - attempt);
    }

    printf("已超过尝试次数限制\n");
    return 1;
}
```

## 统计字符类型

`<ctype.h>` 提供了字符分类函数。传参前转换为 `unsigned char`，可以避免在 `char` 为有符号类型的平台上触发未定义行为。

```c
#include <ctype.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    char input[51];
    int lowercase_count = 0;
    int uppercase_count = 0;
    int digit_count = 0;

    printf("请输入一个长度不超过50的单词：\n");
    if (scanf("%50s", input) != 1) {
        return 1;
    }

    for (size_t i = 0; input[i] != '\0'; i++) {
        unsigned char current = (unsigned char)input[i];

        if (islower(current)) {
            lowercase_count++;
        } else if (isupper(current)) {
            uppercase_count++;
        } else if (isdigit(current)) {
            digit_count++;
        }
    }

    printf("大写字母：%d\n", uppercase_count);
    printf("小写字母：%d\n", lowercase_count);
    printf("数字字符：%d\n", digit_count);
    return 0;
}
```
