# C语言结构体与共用体

## 结构体

结构体将多个相关数据组合成一个整体。每个数据称为结构体的成员，成员可以具有不同的数据类型。

### 定义格式

```c
struct Student {
    char name[100];
    int age;
    double height;
};
```

`Student` 是结构体标签，`name`、`age` 和 `height` 是成员。结构体定义写在函数外时通常可供后续多个函数使用；写在块作用域内时，其标签只在相应作用域中可见。

### 定义和使用结构体变量

```c
#include <stdio.h>

struct Student {
    char name[100];
    int age;
    double height;
};

int main(void)
{
    struct Student student = {"小明", 20, 1.75};

    printf("姓名：%s\n", student.name);
    printf("年龄：%d\n", student.age);
    printf("身高：%.2f\n", student.height);
    return 0;
}
```

使用点运算符 `.` 访问结构体变量的成员。初始化时可以按成员声明顺序提供值，也可以使用指定初始化器，使成员对应关系更清晰：

```c
struct Student student = {
    .name = "小明",
    .age = 20,
    .height = 1.75
};
```

数组成员不能在初始化完成后通过赋值运算符整体赋值。例如修改 `name` 时，可以在确认空间足够后使用字符串复制函数：

```c
#include <string.h>

strcpy(student.name, "小红");
```

## 结构体数组

结构体数组用于保存多个同类型的结构体对象。

```c
#include <stdio.h>

struct Student {
    char name[100];
    int age;
};

int main(void)
{
    struct Student students[] = {
        {"张三", 18},
        {"李四", 19},
        {"王五", 20}
    };
    int count = (int)(sizeof(students) / sizeof(students[0]));

    for (int i = 0; i < count; i++) {
        printf("第%d位学生：%s，%d岁\n",
               i + 1, students[i].name, students[i].age);
    }

    return 0;
}
```

## 使用 `typedef` 定义别名

`typedef` 可以为结构体类型定义更简洁的名称。

```c
typedef struct Character {
    char name[100];
    int attack;
    int defense;
    int health;
} Character;
```

之后可以直接使用别名：

```c
Character player = {"Kuuga", 200, 120, 500};
```

也可以定义不带标签的结构体别名：

```c
typedef struct {
    int x;
    int y;
} Point;
```

结构体可以作为函数参数或返回值，也可以嵌套其他结构体。对象较大且不需要复制时，通常传递指向结构体的指针，并使用 `const` 表明函数不会修改它。

```c
void print_student(const struct Student *student)
{
    printf("%s，%d岁\n", student->name, student->age);
}
```

指针访问成员时使用箭头运算符 `->`，`student->age` 等价于 `(*student).age`。

## 结构体的内存对齐

不同类型通常具有不同的对齐要求。编译器可能在成员之间或结构体末尾插入填充字节，使每个成员位于满足其对齐要求的位置，并让结构体数组中的每个元素都能正确对齐。

```c
#include <stddef.h>
#include <stdio.h>

struct Example {
    char flag;
    int count;
    double value;
};

int main(void)
{
    printf("sizeof = %zu\n", sizeof(struct Example));
    printf("count offset = %zu\n", offsetof(struct Example, count));
    printf("value offset = %zu\n", offsetof(struct Example, value));
    return 0;
}
```

具体的类型大小、对齐值和填充方式由实现和 ABI 决定，不能仅凭成员大小之和判断结构体大小。重新排列成员有时可以减少填充，但也会改变数据布局；涉及文件格式、网络协议或外部接口时不能随意调整。

## 共用体（联合体）

共用体使用 `union` 定义。所有成员共享同一段存储空间，适合表示“同一时刻只取多种类型之一”的数据。

```c
union Number {
    int integer;
    double decimal;
};
```

### 使用共用体

```c
#include <stdio.h>

union Number {
    int integer;
    double decimal;
};

int main(void)
{
    union Number number;

    number.integer = 42;
    printf("%d\n", number.integer);

    number.decimal = 3.14;
    printf("%.2f\n", number.decimal);
    return 0;
}
```

写入 `decimal` 后，共享存储空间中的内容已经改变，之前的 `integer` 值不再保持。通常只读取最近一次写入的成员；读取其他成员的结果具有实现相关限制，不能当作通用类型转换方式。

共用体的大小至少足以容纳最大的成员，并可能为了满足对齐要求而包含额外填充，因此应使用 `sizeof` 获取实际大小。

## 带标签的共用体

为了明确当前保存的是哪个成员，通常将枚举标签和共用体一起放入结构体。

```c
enum ValueType {
    VALUE_INTEGER,
    VALUE_DECIMAL
};

struct Value {
    enum ValueType type;
    union {
        int integer;
        double decimal;
    } data;
};
```

使用时先检查标签，再读取相应成员：

```c
struct Value value = {
    .type = VALUE_DECIMAL,
    .data.decimal = 3.14
};

if (value.type == VALUE_DECIMAL) {
    printf("%.2f\n", value.data.decimal);
}
```

## 结构体与共用体的区别

| 对比项 | 结构体 `struct` | 共用体 `union` |
| --- | --- | --- |
| 使用场景 | 一个对象同时包含多个属性 | 一个值在多种表示中选择一种 |
| 存储方式 | 每个成员拥有各自的存储空间 | 所有成员共享同一段存储空间 |
| 成员有效性 | 多个成员可以同时保存有效值 | 通常只有最近写入的成员有效 |
| 实际大小 | 包含各成员存储及对齐填充 | 至少容纳最大成员并满足对齐要求 |
