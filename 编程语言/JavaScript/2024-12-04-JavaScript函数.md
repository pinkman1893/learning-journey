# JavaScript 函数

## 函数的声明

```javascript
function 函数名(形参) {
    // 函数体
}
```

函数命名规范：

- 与变量命名基本一致。
- 遵循小驼峰命名法。
- 前缀应使用动词，可以使用常见动词约定。

## 函数的调用

```javascript
函数名(实参)
```

## 形参与实参

- 形参的本质是在函数内部声明变量。
- 实参的本质是给函数内部的变量赋值。
- JavaScript 中形参和实参的数量可以不一致：
  - 实参数量不足时，缺少的形参值为 `undefined`。
  - 多出的实参不会绑定到已声明的形参，但仍可通过 `arguments` 对象或剩余参数 `...args` 获取。

## 函数的返回值

- 函数内部不需要输出结果，需要的是返回结果。
- `return` 后面的代码不会继续执行。
- 如果没有设置 `return`，函数默认返回 `undefined`。
- 返回值会返回给函数调用者，相当于在主程序中给调用位置赋值。

## 函数作用域

作用域是限定变量可用范围的代码区域，可以分为全局作用域和局部作用域。

- 在函数中声明的变量具有局部作用域，只在函数内部有效。
- 在非严格模式下，给未声明的标识符赋值可能在全局对象上创建属性；在严格模式下会抛出 `ReferenceError`。这不是 JavaScript 的 bug，应始终先使用 `let`、`const` 或 `var` 声明变量。

### 变量访问原则

访问变量时，先在当前作用域中查找；找不到时再逐级向外层作用域查找。

## 匿名函数

### 函数分类

- 具名函数：声明时具有函数名。
- 匿名函数：声明时没有函数名。

### 函数表达式

函数表达式把匿名函数赋值给变量，再通过变量名调用。

```javascript
let fn = function (形参) {
    // 函数体
}

fn(实参)
```

函数表达式与具名函数声明的不同：

- 具名函数声明后，可以在当前作用域的任意位置调用。
- 函数表达式完成赋值后，只能在赋值位置下方使用。
- Web API 中会使用函数表达式。

### 立即执行函数

立即执行函数用于避免全局变量之间的污染。

写法一：

```javascript
(function (形参) {
    // 函数体
})(实参)
```

写法二：

```javascript
(function (形参) {
    // 函数体
}(实参))
```

立即执行函数本身不强制要求以分号结束。为了防止它与前一条语句连接，常在开头添加分号：

```javascript
;(function () {
    // 函数体
})()
```
