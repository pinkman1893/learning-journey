# JavaScript 对象

## 什么是对象

- 在 JavaScript 中，对象是一种引用数据类型。
- 数组通常通过连续数字索引访问元素；对象使用属性名和值组成键值对，通常通过属性名访问数据。
- 对象可以详细描述某个事物。

## 对象的组成

对象由属性和方法组成：

- 属性：表示对象信息或特征的名词。
  - 属性由属性名和属性值组成。
  - 属性可以理解为依附在对象上的变量。
  - 多个属性之间使用逗号分隔。
  - 属性名可以使用单引号或双引号包裹，但通常省略；属性名包含空格、中横线等不能直接用于标识符的特殊字符时，需要使用引号。
- 方法：表示对象功能或行为的动词，本质是函数。
  - 方法由方法名和函数组成。
  - 方法可以理解为依附在对象上的函数。
  - 多个方法之间使用逗号分隔。

```javascript
let 对象名 = {
    属性名: 属性值,
    方法名: function () {
        // 方法体
    }
}
```

## 声明对象

```javascript
let 对象名 = {}
```

也可以使用 `Object` 构造函数：

```javascript
let 对象名 = new Object()
```

## 使用对象

### 访问属性

可以通过点语法访问对象中的属性值：

```javascript
对象名.属性名
```

也可以通过方括号语法访问：

```javascript
对象名['属性名']
```

不同场景会使用不同写法。

### 修改属性值

```javascript
对象名.属性名 = 新值
```

### 添加属性

```javascript
对象名.新属性 = 新值
```

### 删除属性

```javascript
delete 对象名.属性名
```

`delete` 是正式运算符，上面的写法用于删除对象自身的属性。

## 遍历对象

- 对象中的数据以键值对形式存在，不像数组一样使用连续的数字索引。
- 对象没有用于表示属性数量的 `length` 属性。
- 可以使用 `for...in` 遍历对象的可枚举属性。

```javascript
let obj = {
    userName: '小明',
    age: 18,
    gender: '男'
}

for (let key in obj) {
    console.log(key)      // 打印属性名
    console.log(obj[key]) // 打印属性值
}
```

注意：

- `for...in` 一般用于遍历对象，不建议用来遍历数组。
- `key` 是一个变量，表示当前遍历到的属性名。
- 访问属性值时需要使用 `obj[key]`；此时 `key` 的值相当于一个属性名字符串。
- `key` 获取对象的属性名，`obj[key]` 获取对应的属性值。

## 遍历数组对象

```javascript
let students = [
    { name: '小明', gender: '男' }
]
```
