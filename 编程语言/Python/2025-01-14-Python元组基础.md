# Python 元组基础

## 元组简介

Python 的元组与列表类似，但元组中的元素不可修改。

- 元组是不可变序列。
- 非空元组可以省略括号。
- 单元素元组需要添加逗号，例如 `(40,)`。
- 元组中的元素可以重复。

当数据需要保持不变时，可以优先使用元组；其他情况可以使用列表。

## 创建元组

使用 `()` 或省略括号定义元组。

```python
my_tuple = (1, 2, 3, 4, 5)
print(my_tuple)  # 输出：(1, 2, 3, 4, 5)

single_tuple = (40,)
print(single_tuple)  # 输出：(40,)

tup = 10, 20, 30
print(tup)  # 输出：(10, 20, 30)
```

## 元组解包

解包是把元组中的每个元素赋值给对应的变量。在变量前使用 `*`，可以接收剩余的所有元素。

```python
my_tuple = (10, 20, 30, 50)

a, b, c, d = my_tuple
print(a, b, c, d)  # 输出：10 20 30 50

a, b, *c = my_tuple
print(a, b, c)  # 输出：10 20 [30, 50]

a, *b, c = my_tuple
print(a, b, c)  # 输出：10 [20, 30] 50
```

## 元组操作

### 去重

使用 `set()` 可以去除元组中的重复元素。

```python
test_tuple = (1, 2, 3, 4, 3, 5, 1)
unique_elements = set(test_tuple)
print(unique_elements)  # 输出：{1, 2, 3, 4, 5}
```

### 拼接

使用 `+` 运算符可以把两个元组拼接成一个新元组。

```python
tup1 = (76, 28)
tup2 = ("hao", "yan")
tup3 = tup1 + tup2
print(tup3)  # 输出：(76, 28, 'hao', 'yan')
```

### 删除元组

元组本身不可变，但可以使用 `del` 删除整个元组。

```python
my_tuple = (1, 2, 3)
del my_tuple
# print(my_tuple)  # 会报错：NameError
```

### 切片

元组的切片操作与列表相同，格式为 `tuple[start:end:step]`。

```python
my_tuple = (0, 1, 2, 3, 4, 5)
print(my_tuple[1:4])   # 输出：(1, 2, 3)
print(my_tuple[::-1])  # 输出：(5, 4, 3, 2, 1, 0)
```

## 交换变量的值

使用解包可以快速交换变量的值。

```python
a, b = 100, 200
print("交换前：", a, b)  # 输出：交换前： 100 200

a, b = b, a
print("交换后：", a, b)  # 输出：交换后： 200 100
```

## 常用操作汇总

| 操作 | 方法或示例 |
| --- | --- |
| 创建元组 | `tup = (1, 2, 3)`、`tup = 10, 20`、`(40,)` |
| 解包 | `a, b, *c = (1, 2, 3, 4)` |
| 去重 | `set(tup)` |
| 拼接 | `tup1 + tup2` |
| 删除 | `del tup` |
| 切片 | `tup[start:end:step]` |
| 交换 | `a, b = b, a` |

元组是一种高效、简洁的数据结构，适合存储不可变数据。
