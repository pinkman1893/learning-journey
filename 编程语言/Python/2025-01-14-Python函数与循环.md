# Python 函数与循环

## 函数基础

### 定义与调用

使用 `def` 关键字定义函数，函数体通过缩进表示。函数定义后，需要显式调用才会执行。

```python
def say_hello():
    print("Hello!")

say_hello()  # 输出：Hello!

def add_two_numbers(a, b):
    return a + b

result = add_two_numbers(10, 20)
print(result)  # 输出：30
```

### 参数类型

#### 位置参数

调用函数时，实参会按照位置依次传给形参。

```python
def greet(name, age):
    print(f"My name is {name}, and I am {age} years old.")

greet("Alice", 25)
```

#### 默认参数

参数可以预先设置默认值。调用时如果没有传入对应实参，就会使用默认值。

```python
def greet(name, age=30):
    print(f"My name is {name}, and I am {age} years old.")

greet("Bob")  # 输出：My name is Bob, and I am 30 years old.
```

#### 可变位置参数

`*args` 用于接收不定数量的位置参数，传入的参数会被打包为元组。

```python
def sum_numbers(*args):
    return sum(args)

print(sum_numbers(1, 2, 3, 4))  # 输出：10
```

#### 可变关键字参数

`**kwargs` 用于接收不定数量的键值对参数，传入的参数会被打包为字典。

```python
def display_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

display_info(name="Alice", age=25, city="New York")
```

### 返回值

使用 `return` 返回函数的执行结果。一个函数可以返回多个值，此时这些值会组成一个元组。

```python
def calculate(a, b):
    return a + b, a - b

result = calculate(10, 5)
print(result)  # 输出：(15, 5)
```

### 变量作用域

- 局部变量：在函数内部定义，只在函数内部有效。
- 全局变量：在函数外部定义，可以在全局范围内使用。

```python
x = 10  # 全局变量

def func():
    y = 5  # 局部变量
    print(x + y)

func()  # 输出：15
```

### 常用内置函数

| 函数 | 描述 |
| --- | --- |
| `enumerate()` | 遍历可迭代对象时，同时取得索引和值 |
| `zip()` | 将多个可迭代对象中的元素配对 |

```python
for index, value in enumerate(["a", "b", "c"]):
    print(f"Index {index}: Value {value}")

for a, b in zip([1, 2, 3], ["x", "y", "z"]):
    print(f"{a} -> {b}")
```

## 循环语句

### `range()` 的用法

- `range(stop)`：生成从 `0` 到 `stop - 1` 的整数序列。
- `range(start, stop)`：生成从 `start` 到 `stop - 1` 的整数序列。
- `range(start, stop, step)`：按照 `step` 指定的步长生成整数序列。

```python
print(list(range(5)))         # 输出：[0, 1, 2, 3, 4]
print(list(range(1, 6)))      # 输出：[1, 2, 3, 4, 5]
print(list(range(1, 10, 2)))  # 输出：[1, 3, 5, 7, 9]
```

### `for` 循环

`for` 循环用于遍历序列、范围或其他可迭代对象。循环正常结束且没有被 `break` 中断时，可以继续执行对应的 `else` 代码块。

```python
for i in range(1, 6):
    print(i)  # 依次输出：1 2 3 4 5

for i in range(3):
    print(i)
else:
    print("循环结束")
```

### 循环控制

- `break`：结束当前循环。
- `continue`：跳过本次循环的剩余部分，进入下一次循环。
- `exit()` 可用于结束交互式程序；正式脚本通常使用 `sys.exit()`，并先导入 `sys`。

```python
for i in range(5):
    if i == 3:
        break
    print(i)  # 依次输出：0 1 2
```

### `while` 循环

当条件为 `True` 时，`while` 会重复执行循环体；条件变为 `False` 后结束。与 `for` 相同，循环正常结束时也可以执行 `else` 代码块。

```python
i = 1
while i <= 5:
    print(i)
    i += 1
else:
    print("循环结束")
```

### 死循环

使用 `while True` 可以创建死循环，需要通过 `break` 或外部条件终止。

```python
while True:
    command = input("输入 'exit' 退出: ")
    if command == "exit":
        break
    print("你输入了:", command)
```
