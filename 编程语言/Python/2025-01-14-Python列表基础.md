# Python 列表基础

## 创建列表

列表使用方括号 `[]` 定义，元素之间用逗号分隔。列表中的元素可以是任意数据类型，也可以混合存放不同类型的值。

```python
i_list = [2, 5, 8]
s_list = ["a", "b", "c"]
h_list = [1, "a", 2, "b"]

print(i_list)  # 输出：[2, 5, 8]
print(s_list)  # 输出：['a', 'b', 'c']
print(h_list)  # 输出：[1, 'a', 2, 'b']
```

## 增加元素

### 增加单个元素

- `append()`：在列表末尾追加一个元素。
- `insert(index, value)`：在指定索引位置插入元素。

```python
i_list = [2, 5, 8]
i_list.append(10)
print(i_list)  # 输出：[2, 5, 8, 10]

s_list = ["a", "b", "c"]
s_list.insert(1, "s")
print(s_list)  # 输出：['a', 's', 'b', 'c']
```

### 合并或扩展列表

- `+` 运算符：合并两个列表并生成新列表。
- `extend()`：使用另一个列表扩展当前列表。

```python
i_list = [2, 5, 8, 10]
s_list = ["a", "s", "b", "c"]

combined_list = i_list + s_list
print(combined_list)  # 输出：[2, 5, 8, 10, 'a', 's', 'b', 'c']

i_list.extend(s_list)
print(i_list)  # 输出：[2, 5, 8, 10, 'a', 's', 'b', 'c']
```

## 删除元素

- `remove(value)`：按照值删除第一个匹配的元素。
- `pop(index)`：按照索引删除元素，省略索引时删除最后一个元素。
- `del`：按照索引删除元素。

```python
s_list = ["a", "s", "b", "c"]
s_list.remove("s")
print(s_list)  # 输出：['a', 'b', 'c']

i_list = [2, 5, 8]
i_list.pop(-1)
print(i_list)  # 输出：[2, 5]

del i_list[-1]
print(i_list)  # 输出：[2]
```

## 查找和访问元素

使用 `in` 可以判断一个值是否存在于列表中；使用索引或切片可以访问一个或多个元素。

```python
i_list = [2, 5, 8]
s_list = ["a", "b", "c", "d"]

print(5 in i_list)    # 输出：True
print("z" in s_list)  # 输出：False

print(s_list[2])   # 输出：c
print(s_list[2:])  # 输出：['c', 'd']
```

## 修改元素

通过索引直接赋值，可以修改列表中对应位置的元素。

```python
s_list = ["a", "b", "c", "d"]
s_list[0] = "A"
print(s_list)  # 输出：['A', 'b', 'c', 'd']
```

## 列表排序

`sort()` 默认按照升序排列；传入 `reverse=True` 时按照降序排列。

```python
s_list = ["A", "b", "c", "d"]

s_list.sort()
print(s_list)  # 输出：['A', 'b', 'c', 'd']

s_list.sort(reverse=True)
print(s_list)  # 输出：['d', 'c', 'b', 'A']
```

## 复制列表

`copy()` 返回当前列表的副本。

```python
s_list = ["d", "c", "b", "A"]
copied_list = s_list.copy()
print(copied_list)  # 输出：['d', 'c', 'b', 'A']
```

## 长度与计数

- `len()`：获取列表中的元素个数。
- `count(value)`：统计指定值出现的次数。

```python
s_list = ["d", "c", "b", "A"]

print(len(s_list))       # 输出：4
print(s_list.count("c"))  # 输出：1
```

## 常用操作汇总

| 功能 | 方法 |
| --- | --- |
| 创建列表 | `[元素1, 元素2, ...]` |
| 增加元素 | `append()`、`insert()`、`+`、`extend()` |
| 删除元素 | `remove()`、`pop()`、`del` |
| 查找元素 | `in`、索引、切片 |
| 修改元素 | 通过索引直接赋值 |
| 排序 | `sort()` |
| 复制 | `copy()` |
| 长度 | `len()` |
| 计数 | `count()` |
