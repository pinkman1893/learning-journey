# Python 字典基础

## 字典简介

字典是无序的键值对集合，使用花括号 `{}` 定义。每个键值对使用冒号 `:` 分隔，键是唯一的，值可以重复。

- 键必须是不可变的数据类型，例如字符串、数字或元组。
- 值可以是任意数据类型。
- 字典是动态的，可以随时添加、修改或删除键值对。

```python
my_dict = {"name": "Alice", "age": 25, "city": "New York"}
print(my_dict)  # 输出：{'name': 'Alice', 'age': 25, 'city': 'New York'}
```

## 访问字典元素

可以使用键直接访问对应的值，也可以使用 `get()` 获取值，并在键不存在时指定默认值。

```python
print(my_dict["name"])  # 输出：Alice
print(my_dict.get("age"))  # 输出：25
print(my_dict.get("gender", "Not specified"))  # 输出：Not specified
```

## 添加和更新元素

通过键赋值，可以添加新的键值对或更新已有键的值。

```python
my_dict["gender"] = "Female"
print(my_dict)
# 输出：{'name': 'Alice', 'age': 25, 'city': 'New York', 'gender': 'Female'}

my_dict["age"] = 30
print(my_dict)
# 输出：{'name': 'Alice', 'age': 30, 'city': 'New York', 'gender': 'Female'}
```

## 删除字典元素

- `pop(key)`：删除指定键并返回对应的值。
- `popitem()`：随机删除一个键值对，Python 3.7 及以后返回最后插入的键值对。
- `del`：删除指定键或整个字典。
- `clear()`：清空字典。

```python
value = my_dict.pop("city")
print(value)    # 输出：New York
print(my_dict)  # 输出：{'name': 'Alice', 'age': 30, 'gender': 'Female'}

last_item = my_dict.popitem()
print(last_item)  # 输出：('gender', 'Female')

del my_dict
# print(my_dict)  # 会报错：NameError

my_dict = {"name": "Alice", "age": 30}
my_dict.clear()
print(my_dict)  # 输出：{}
```

## 常用方法

| 方法 | 描述 |
| --- | --- |
| `keys()` | 返回字典中的所有键 |
| `values()` | 返回字典中的所有值 |
| `items()` | 返回所有键值对 |
| `copy()` | 返回字典的浅拷贝 |
| `update(other_dict)` | 把另一个字典的键值对合并到当前字典 |

```python
my_dict = {"name": "Alice", "age": 30}

print(my_dict.keys())    # 输出：dict_keys(['name', 'age'])
print(my_dict.values())  # 输出：dict_values(['Alice', 30])
print(my_dict.items())   # 输出：dict_items([('name', 'Alice'), ('age', 30)])

copy_dict = my_dict.copy()
print(copy_dict)  # 输出：{'name': 'Alice', 'age': 30}

other_dict = {"gender": "Female", "city": "New York"}
my_dict.update(other_dict)
print(my_dict)
# 输出：{'name': 'Alice', 'age': 30, 'gender': 'Female', 'city': 'New York'}
```

## 遍历字典

```python
for key in my_dict.keys():
    print(key)

for value in my_dict.values():
    print(value)

for key, value in my_dict.items():
    print(f"{key}: {value}")
```

## 字典嵌套

字典可以嵌套字典或其他数据结构。

```python
nested_dict = {
    "user1": {"name": "Alice", "age": 25},
    "user2": {"name": "Bob", "age": 30}
}

print(nested_dict["user1"]["name"])  # 输出：Alice
```

## 常用操作汇总

| 操作 | 方法或运算符 |
| --- | --- |
| 访问值 | `dict[key]`、`dict.get(key)` |
| 添加或更新 | `dict[key] = value` |
| 删除元素 | `pop()`、`popitem()`、`del`、`clear()` |
| 查看键或值 | `keys()`、`values()`、`items()` |
| 合并字典 | `update()` |
| 拷贝字典 | `copy()` |

字典广泛用于键值对存储和数据处理场景。
