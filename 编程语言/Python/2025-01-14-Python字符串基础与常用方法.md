# Python 字符串基础与常用方法

## 创建字符串

可以使用单引号或双引号创建字符串。根据字符串内部包含的引号选择写法，可以减少转义字符的使用。

```python
a = "I'm a teacher!"
b = 'My name is "Tom"'

print(a)  # 输出：I'm a teacher!
print(b)  # 输出：My name is "Tom"
```

连续三个单引号或双引号可以创建多行字符串。

```python
resume = '''name="Alice"
company="Tech Co."
age=25'''

print(resume)
```

输出：

```text
name="Alice"
company="Tech Co."
age=25
```

## 空字符串与 `len()`

空字符串的长度为 `0`，常用于表示没有内容。`len()` 可以计算字符串包含的字符数，空格也会计入长度。

```python
empty_str = ""
print(len(empty_str))  # 输出：0

text = "Python 编程"
print(len(text))  # 输出：9
```

## 转义字符

反斜杠 `\` 可以表示一些特殊字符。

| 转义字符 | 作用 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 横向制表符 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |

```python
escaped_str = "Hello,\nPython\tWorld!"
print(escaped_str)
```

## 字符串切片

切片格式为 `[start:end:step]`：

- `start`：起始索引，默认从开头开始。
- `end`：结束索引，不包含该位置。
- `step`：步长，负数表示反向取值。

```python
text = "abcdefghijklmnopqrstuvwxyz"

print(text[2:5])   # 输出：cde
print(text[:5])    # 输出：abcde
print(text[::2])   # 输出：acegikmoqsuwy
print(text[::-1])  # 输出：zyxwvutsrqponmlkjihgfedcba
```

## `split()` 与 `join()`

- `split()`：按照指定分隔符把字符串分割成列表。
- `join()`：使用指定分隔符把一组字符串连接成新字符串。

```python
sentence = "to be or not to be"

words = sentence.split()
print(words)  # 输出：['to', 'be', 'or', 'not', 'to', 'be']

words_2 = sentence.split("be")
print(words_2)  # 输出：['to ', ' or not to ', '']

joined_sentence = "-".join(words)
print(joined_sentence)  # 输出：to-be-or-not-to-be
```
