# Python 数学函数

## `abs()`：获取绝对值

- 功能：返回数字的绝对值。
- 语法：`abs(x)`，参数 `x` 是数字或可转为数字的对象。

```python
print(abs(-5))    # 输出：5
print(abs(3.14))  # 输出：3.14
```

## `divmod()`：获取商和余数

- 功能：返回包含商和余数的元组 `(a // b, a % b)`。
- 语法：`divmod(a, b)`，其中 `a` 是被除数，`b` 是非零除数。

```python
result = divmod(10, 3)
print(result)  # 输出：(3, 1)

quotient, remainder = divmod(15, 4)
print(f"商：{quotient}, 余数：{remainder}")  # 输出：商：3, 余数：3
```

## `sum()`：求和

- 功能：对列表、元组、集合等可迭代对象中的元素求和。
- 语法：`sum(iterable, start=0)`，`start` 是可选的初始值。

```python
numbers = [1, 2, 3, 4]
print(sum(numbers))      # 输出：10
print(sum(numbers, 10))  # 输出：20
```

## `round()`：四舍五入

- 功能：返回浮点数四舍五入后的值，可以指定保留的小数位数。
- 语法：`round(number, ndigits)`，`ndigits` 为可选参数。

```python
print(round(3.14159, 2))  # 输出：3.14
print(round(3.5))         # 输出：4
```

## `pow()`：计算幂

- 功能：返回 `x` 的 `y` 次幂，也可以进行取模运算。
- 语法：`pow(x, y, z=None)`，`x` 为底数，`y` 为指数，`z` 为可选的模。

```python
print(pow(2, 3))     # 输出：8
print(pow(2, 3, 3))  # 输出：2，即 2 ** 3 % 3
```

## `min()`：获取最小值

`min()` 可以返回可迭代对象或多个参数中的最小值。

```python
print(min(1, 2, 3, -1))  # 输出：-1

numbers = [10, 20, 30]
print(min(numbers))  # 输出：10
```

## `max()`：获取最大值

`max()` 可以返回可迭代对象或多个参数中的最大值。

```python
print(max(1, 2, 3, -1))  # 输出：3

numbers = [10, 20, 30]
print(max(numbers))  # 输出：30
```
