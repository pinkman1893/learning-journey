# Python 文件操作与异常处理

## I/O 流与文件操作

### 流的模式

- `r`：输入流，用于读取文件。
- `w`：输出流，用于写入文件，会覆盖原内容。
- `a`：追加流，用于写入文件，不覆盖原内容。
- `t`：字符流，默认模式，适用于文本文件。
- `b`：字节流，适用于二进制文件。

### 文件操作流程

1. 打开文件。
2. 通过输入流读取，或通过输出流写入。
3. 关闭文件。

### `open()` 函数

`open(file, mode, encoding)` 用于打开文件：

- `file`：文件路径或文件名。
- `mode`：文件打开模式，例如 `rt`、`wb`。
- `encoding`：编码格式，例如 `utf-8`、`gbk`。

| 模式 | 描述 |
| --- | --- |
| `r` | 以只读模式打开文件 |
| `w` | 以写入模式打开文件，会覆盖原内容 |
| `a` | 以追加模式打开文件 |
| `rb` | 以二进制只读模式打开文件 |
| `wb` | 以二进制写入模式打开文件 |

```python
f = open("example.txt", mode="w", encoding="utf-8")
f.write("Hello, Python IO!")
f.close()
```

### I/O 对象的常用方法

| 方法或属性 | 描述 |
| --- | --- |
| `close()` | 关闭流 |
| `closed` | 判断流是否关闭 |
| `read(size)` | 读取指定大小的数据 |
| `readline()` | 读取一行数据 |
| `readlines()` | 读取多行数据并返回列表 |
| `write(data)` | 写入数据 |
| `writelines()` | 写入多行数据 |
| `flush()` | 刷新流，把缓冲区内容写入文件 |

```python
with open("example.txt", mode="r", encoding="utf-8") as f:
    content = f.read()
    print(content)

with open("example.txt", mode="a", encoding="utf-8") as f:
    f.writelines(["\nLine 1", "\nLine 2"])
```

### 字符流与字节流

字符流默认使用 `t` 模式处理文本文件，需要指定相应的编码格式。字节流使用 `b` 模式操作图片、音频等二进制文件。

```python
with open("binary_file.bin", mode="wb") as f:
    f.write(b"\xDE\xAD\xBE\xEF")
```

### 逐行读取文件

```python
with open("example.txt", mode="r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

### 复制文件

```python
with open("source.txt", mode="r", encoding="utf-8") as src:
    with open("dest.txt", mode="w", encoding="utf-8") as dest:
        dest.write(src.read())
```

## 异常处理

### 捕获异常

使用 `try...except` 结构捕获并处理异常。

```python
try:
    # 可能产生异常的代码
    pass
except 异常类型:
    # 处理异常的代码
    pass
```

示例：

```python
try:
    print("开始读取文件...")
    open("nonexistent_file.txt", "r")
except IOError:
    print("发生 IOError 异常")
```

输出：

```text
开始读取文件...
发生 IOError 异常
```

### 捕获多个异常

使用元组可以捕获多个异常类型。

```python
try:
    num = int("not_a_number")
except (ValueError, TypeError):
    print("捕获到 ValueError 或 TypeError")
```

### 捕获所有异常

不指定异常类型可以捕获所有异常，但需要谨慎使用。

```python
try:
    result = 10 / 0
except:
    print("捕获到一个异常")
```

### 获取异常信息

使用 `as` 关键字可以获取异常描述信息。

```python
try:
    print(num)
except NameError as error_msg:
    print(f"捕获到 NameError: {error_msg}")
```

可能输出：

```text
捕获到 NameError: name 'num' is not defined
```

### `else` 子句

没有捕获到异常时，会执行 `else` 语句块。

```python
try:
    result = 10 / 2
except ZeroDivisionError:
    print("除零错误")
else:
    print("没有捕获到异常，计算结果是:", result)
```

### `finally` 子句

无论是否发生异常，`finally` 子句中的代码都会执行。

```python
try:
    f = open("example.txt", "r")
except FileNotFoundError:
    print("文件不存在")
finally:
    print("无论是否发生异常，这里都会执行")
```

文件操作中也可以在 `finally` 中关闭已经成功打开的文件：

```python
f = None
try:
    f = open("example.txt", mode="r", encoding="utf-8")
    print(f.read())
except FileNotFoundError:
    print("文件不存在")
finally:
    if f is not None:
        f.close()
```
