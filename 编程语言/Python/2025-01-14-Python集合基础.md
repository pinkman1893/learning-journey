# Python 集合基础

## 集合定义

集合（`set`）是一种无序、元素不可重复的数据结构，使用花括号 `{}` 定义。当集合内有重复元素时，会自动去重。

```python
s = {1, 2, 3, 3, 4}
print(s)  # 输出：{1, 2, 3, 4}
```

## 使用集合去重

可以把列表转换为集合以去重，再转换回列表。

```python
li = [1, 2, 3, 1, 1, 2, 3]
unique_list = list(set(li))
print(unique_list)  # 输出：[1, 2, 3]
```

## 成员操作

使用 `in` 和 `not in` 可以判断元素是否存在于集合中。

```python
s = {6, 7, 8, 9}
print(6 in s)       # 输出：True
print(10 not in s)  # 输出：True
```

## 迭代与枚举

使用 `for` 循环可以迭代集合，使用 `enumerate()` 可以同时获取索引和元素。

```python
s = {6, 7, 8, 9}

for i in s:
    print(i)

for index, value in enumerate(s):
    print(f"index: {index}, value: {value}")
```

## 增加和删除元素

### 增加元素

- `add(value)`：添加单个元素。
- `update(iterable)`：添加多个元素。

```python
s = {1, 2, 3}
s.add(4)
print(s)  # 输出：{1, 2, 3, 4}

s.update([5, 6])
print(s)  # 输出：{1, 2, 3, 4, 5, 6}
```

### 删除元素

- `pop()`：随机删除并返回一个元素。
- `remove(value)`：删除指定元素，元素不存在时会报错。
- `discard(value)`：删除指定元素，元素不存在时不会报错。

```python
s = {1, 2, 3, 4, 5, 6}

s.pop()
s.remove(2)
s.discard(10)
```

## 集合之间的关系

### 交集

使用 `s1.intersection(s2)` 或 `s1 & s2`。

```python
s1 = {1, 2, 3}
s2 = {2, 3, 4}
print(s1.intersection(s2))  # 输出：{2, 3}
```

### 并集

使用 `s1.union(s2)` 或 `s1 | s2`。

```python
print(s1.union(s2))  # 输出：{1, 2, 3, 4}
```

### 差集

使用 `s1.difference(s2)` 或 `s1 - s2`。

```python
print(s1.difference(s2))  # 输出：{1}
```

### 超集、子集与无交集

- `s1.issuperset(s2)`：判断 `s1` 是否是 `s2` 的超集。
- `s1.issubset(s2)`：判断 `s1` 是否是 `s2` 的子集。
- `s1.isdisjoint(s2)`：判断 `s1` 与 `s2` 是否没有交集。

```python
s3 = {1, 2}
s4 = {1, 2, 3}

print(s4.issuperset(s3))  # 输出：True
print(s3.issubset(s4))    # 输出：True
print(s3.isdisjoint(s4))  # 输出：False
```

## 常用操作汇总

| 操作 | 方法或运算符 |
| --- | --- |
| 去重 | `set(iterable)` |
| 成员操作 | `in`、`not in` |
| 添加元素 | `add(value)`、`update(iterable)` |
| 删除元素 | `pop()`、`remove(value)`、`discard(value)` |
| 交集 | `s1.intersection(s2)` 或 `s1 & s2` |
| 并集 | `s1.union(s2)` 或 `s1 \| s2` |
| 差集 | `s1.difference(s2)` 或 `s1 - s2` |
| 子集或超集 | `issubset()`、`issuperset()` |
| 无交集 | `isdisjoint()` |

集合适合用于数据去重和集合运算等场景。
