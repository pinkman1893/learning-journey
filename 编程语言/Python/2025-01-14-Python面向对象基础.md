# Python 面向对象基础

## 类和对象

- 类（Class）是一种模板，定义了某类事物的共同特征和行为。
- 对象（Object）是类的具体实例。

例如，在“水果商店”程序中，类可以定义水果的名称和价格，对象则表示具体的苹果或橘子。

```python
class Fruit:
    def __init__(self, name, price):
        self.name = name
        self.price = price

apple = Fruit("苹果", 20)
orange = Fruit("橘子", 3)

print(apple.name, apple.price)    # 输出：苹果 20
print(orange.name, orange.price)  # 输出：橘子 3
```

## 属性和方法

- 属性表示事物的特征，例如水果的名称、价格。
- 方法表示事物的行为，例如购买水果、计算总价。

```python
class Person:
    def __init__(self, name, money):
        self.name = name
        self.money = money

    def buy(self, fruit, quantity):
        cost = fruit.price * quantity
        if self.money >= cost:
            self.money -= cost
            print(f"{self.name} 买了 {quantity} 斤 {fruit.name}，花了 {cost} 元，还剩 {self.money} 元")
        else:
            print(f"{self.name} 的钱不够，无法购买 {fruit.name}")

person = Person("小明", 50)
apple = Fruit("苹果", 20)
person.buy(apple, 2)
```

## 封装

封装是把属性和方法放在类中，并隐藏不需要由使用者直接了解或操作的实现细节。

单下划线 `_` 表示内部使用的约定；双下划线 `__` 会触发名称改写，可减少从类外直接访问。

```python
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.__balance = balance

    def deposit(self, amount):
        self.__balance += amount
        print(f"{self.owner} 存入 {amount} 元，当前余额 {self.__balance} 元")

    def withdraw(self, amount):
        if amount > self.__balance:
            print(f"余额不足，无法取出 {amount} 元")
        else:
            self.__balance -= amount
            print(f"{self.owner} 取出 {amount} 元，当前余额 {self.__balance} 元")

account = BankAccount("小红", 100)
account.deposit(50)    # 输出：小红 存入 50 元，当前余额 150 元
account.withdraw(200)  # 输出：余额不足，无法取出 200 元
```

## 继承

继承可以让子类复用父类的通用属性和方法，同时添加自己的特有内容。例如，苹果和橘子都可以继承水果类。

```python
class Fruit:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def show_info(self):
        print(f"{self.name} 的价格是 {self.price} 元/斤")

class Apple(Fruit):
    def __init__(self, price, color):
        super().__init__("苹果", price)
        self.color = color

class Orange(Fruit):
    def __init__(self, price, size):
        super().__init__("橘子", price)
        self.size = size

apple = Apple(20, "红色")
orange = Orange(3, "小")

apple.show_info()
orange.show_info()
```

## 多态

不同对象可以通过相同的方法表现出不同的行为。例如，苹果和橘子都有 `show_info()` 方法，但会输出各自的信息。

```python
class Fruit:
    def show_info(self):
        pass

class Apple(Fruit):
    def show_info(self):
        print("苹果是红色的，20 元/斤")

class Orange(Fruit):
    def show_info(self):
        print("橘子是小的，3 元/斤")

fruits = [Apple(), Orange()]
for fruit in fruits:
    fruit.show_info()
```

输出：

```text
苹果是红色的，20 元/斤
橘子是小的，3 元/斤
```
