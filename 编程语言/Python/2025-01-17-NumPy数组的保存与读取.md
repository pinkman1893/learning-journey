# NumPy 数组的保存与读取

## 保存与读取单个数组

- 使用 `np.save(filename, array)` 将单个数组保存为 `.npy` 文件。
- `.npy` 是 NumPy 专用的二进制格式，存储效率较高。
- 使用 `np.load(filename)` 读取 `.npy` 文件。

```python
import numpy as np

arr = np.array([[1, 2, 3], [4, 5, 6]])

# 保存数组
np.save("array.npy", arr)

# 读取数组
loaded_arr = np.load("array.npy")
print("读取的数组：\n", loaded_arr)
```

## 保存与读取多个数组

- 使用 `np.savez(filename, **arrays)` 将多个数组保存到 `.npz` 文件。
- 推荐使用 `name=array` 的方式为数组命名，便于读取时通过键名访问。
- `np.load(filename)` 会返回一个类似字典的对象，`files` 属性中保存着所有数组的键名。

```python
arr1 = np.array([1, 2, 3])
arr2 = np.array([[4, 5, 6], [7, 8, 9]])

# 保存多个数组
np.savez("arrays.npz", array1=arr1, array2=arr2)

# 读取多个数组
data = np.load("arrays.npz")
print("数组名称：", data.files)
print("数组1：", data["array1"])
print("数组2：\n", data["array2"])
```

## 保存与读取文本文件

- 使用 `np.savetxt(filename, array, delimiter)` 将数组保存为文本格式，例如 CSV。
- 可以通过 `fmt` 指定数据格式，通过 `delimiter` 指定分隔符。
- 使用 `np.loadtxt(filename, delimiter)` 从文本文件中读取数组。

```python
arr = np.array([[1.5, 2.5, 3.5], [4.5, 5.5, 6.5]])

# 保存为文本文件
np.savetxt("array.txt", arr, fmt="%.2f", delimiter=",")

# 从文本文件读取
arr_from_txt = np.loadtxt("array.txt", delimiter=",")
print("从文本文件读取的数组：\n", arr_from_txt)
```

## 保存与读取压缩文件

使用 `np.savez_compressed()` 可以将多个数组保存为压缩的 `.npz` 文件，从而节省存储空间。

```python
np.savez_compressed("compressed_arrays.npz", array1=arr1, array2=arr2)

compressed_data = np.load("compressed_arrays.npz")
print("压缩文件中的数组1：", compressed_data["array1"])
```

| 方法 | 是否压缩数据 | 特点 |
| --- | --- | --- |
| `np.savez()` | 否，仅打包 | 保存速度快，但文件较大 |
| `np.savez_compressed()` | 是，使用 zlib 压缩 | 文件较小，但保存和读取速度较慢 |
