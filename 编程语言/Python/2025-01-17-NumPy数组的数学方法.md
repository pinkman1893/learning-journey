# NumPy 数组的数学方法

## 数组的基本数学运算

| 运算类型 | 函数 | 代码示例 | 结果 |
| --- | --- | --- | --- |
| 加法 | `np.add(a, b)` | `np.add([0, 1, 2, 3], [1, 2, 3, 4])` | `[1, 3, 5, 7]` |
| 减法 | `np.subtract(a, b)` | `np.subtract([0, 1, 2, 3], [1, 2, 3, 4])` | `[-1, -1, -1, -1]` |
| 乘法 | `np.multiply(a, b)` | `np.multiply([0, 1, 2, 3], [1, 2, 3, 4])` | `[0, 2, 6, 12]` |
| 除法 | `np.divide(a, b)` | `np.divide([0, 1, 2, 3], [1, 2, 3, 4])` | `[0.0, 0.5, 0.6667, 0.75]` |
| 幂运算 | `np.power(a, b)` | `np.power([0, 1, 2, 3], 2)` | `[0, 1, 4, 9]` |
| 取余数 | `np.mod(a, b)` | `np.mod([0, 1, 2, 3], [1, 2, 3, 4])` | `[0, 1, 2, 3]` |
| 同时取商和余数 | `np.divmod(a, b)` | `np.divmod([0, 1, 2, 3], [1, 2, 3, 4])` | `(array([0, 0, 0, 0]), array([0, 1, 2, 3]))` |

## 数学统计函数

| 统计方法 | 函数 | 代码示例 | 说明 |
| --- | --- | --- | --- |
| 均值 | `np.mean(a)` | `np.mean([1, 2, 3, 4])` | 求数组的平均值 |
| 方差 | `np.var(a)` | `np.var([1, 2, 3, 4])` | 求数组的方差 |
| 标准差 | `np.std(a)` | `np.std([1, 2, 3, 4])` | 求数组的标准差 |

## 常用单变量函数

| 函数 | 功能 | 代码示例 |
| --- | --- | --- |
| `np.abs(a)` | 计算数组元素的绝对值 | `np.abs([-1, -2, 3])` |
| `np.sqrt(a)` | 计算数组元素的平方根 | `np.sqrt([4, 9, 16])` |
| `np.exp(a)` | 计算数组元素的指数 | `np.exp([1, 2])` |
| `np.log(a)` | 计算自然对数 | `np.log([1, np.e, np.e**2])` |
| `np.ceil(a)` | 向上取整 | `np.ceil([1.2, 2.8])` |
| `np.floor(a)` | 向下取整 | `np.floor([1.2, 2.8])` |
| `np.rint(a)` | 四舍五入 | `np.rint([1.5, 2.3])` |
| `np.isnan(a)` | 检测是否为 NaN | `np.isnan([1, np.nan])` |
| `np.isinf(a)` | 检测是否为无穷大 | `np.isinf([1, np.inf])` |

## 常用双变量函数

| 函数 | 功能 | 代码示例 |
| --- | --- | --- |
| `np.add(a, b)` | 元素逐个相加 | `np.add([1, 2], [3, 4])` |
| `np.subtract(a, b)` | 元素逐个相减 | `np.subtract([5, 6], [3, 4])` |
| `np.multiply(a, b)` | 元素逐个相乘 | `np.multiply([1, 2], [3, 4])` |
| `np.divide(a, b)` | 元素逐个相除 | `np.divide([4, 6], [2, 3])` |
| `np.maximum(a, b)` | 元素逐个取最大值 | `np.maximum([1, 3], [2, 2])` |
| `np.minimum(a, b)` | 元素逐个取最小值 | `np.minimum([1, 3], [2, 2])` |

## 其他数学函数

| 函数 | 功能 | 代码示例 |
| --- | --- | --- |
| `np.modf(a)` | 将数组的小数和整数部分分离 | `np.modf([1.5, 2.3])` |
| `np.sign(a)` | 返回元素的符号 `-1`、`0` 或 `1` | `np.sign([-5, 0, 3])` |
| `np.trunc(a)` | 向零取整 | `np.trunc([-1.7, 1.8])` |
| `np.cos(a)` | 计算余弦值 | `np.cos([0, np.pi/2])` |
| `np.sin(a)` | 计算正弦值 | `np.sin([0, np.pi/2])` |
| `np.tan(a)` | 计算正切值 | `np.tan([0, np.pi/4])` |
