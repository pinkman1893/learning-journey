# Pandas 统计分析

## 概览

- Pandas 建立在 NumPy 之上，能够提供高性能的矩阵运算。
- Pandas 提供二维表格的数据抽象，支持复杂查询、增删改查、多维索引、时间序列处理和数据清洗等操作。

二维表格的数据可以来自文本文件、Excel 文件、CSV 文件和数据库等。

- **Series**：代表二维表格的一行或一列，是带索引的一维数组。
- **DataFrame**：代表整个二维表格，由一组有序的列组成，可以看作由 Series 组成的字典。

## 文件读取与存储

### 文本文件

Pandas 提供 `read_table()` 读取文本文件，提供 `read_csv()` 读取 CSV 文件。

- `filepath`：文件路径。
- `sep`：指定分隔符；分隔符错误会导致数据无法正确拆分。
- `header`：指定列名所在行。若为 `None`，则使用默认列名。
- `encoding`：文件编码，如 `gbk`、`utf-8`。

![](assets/247740835/51c06640d745.png)

![](assets/247740835/847277ee3225.png)

```python
musicdata1 = pd.read_csv("musicdata.csv", encoding="gbk")
print("信息表长度为：", len(musicdata1))
print(musicdata1)
```

使用 `DataFrame.to_csv()` 将 DataFrame 保存为文本文件：

```python
musicdata.to_csv("./tmp/musicdataInfo.csv", sep=";", index=False)
print(os.listdir("./tmp"))
```

### Excel 文件

Pandas 提供 `read_excel()` 读取 `xls` 和 `xlsx` 文件。

- `io`：文件路径。
- `sheet_name`：指定工作表，默认为 `0`。
- `header`、`index_col`、`skiprows` 等参数与 CSV 读取类似。

```python
musicdata = pd.read_excel("musicdata.xlsx")
print("信息表长度为：", len(musicdata))
```

使用 `DataFrame.to_excel()` 存储 Excel 文件：

```python
musicdata.to_excel("./tmp/musicdata.xlsx")
print(os.listdir("./tmp"))
```

## Series

### 概述与创建

- Series 由一组数据（`data`）和一组索引（`index`）组成。
- Series 使用 NumPy 存储值。

```python
pandas.Series(
    data=None,
    index=None,
    dtype=None,
    name=None,
    copy=None,
    fastpath=False,
)
```

- `data`：允许使用 array-like、Iterable 或字典。
- `index`：必须和 `data` 的元素数量相同。默认索引为 `0, 1, ..., n-1`；如果 `data` 是字典且未提供 `index`，则使用字典的键作为索引。

![](assets/247740835/da77cb116957.png)

### 查询

> 基于标签查询时，切片是闭区间。

![](assets/247740835/7b28ea5c3b89.png)

使用 `loc` 基于标签查询：

```python
ser.loc["重庆"]
ser.loc["广州":"深圳"]
```

使用 `iloc` 基于位置查询：

```python
ser.iloc[4]
ser.iloc[2:4]
```

使用布尔索引筛选数据：

```python
ser[ser > 10000]
```

### 修改

```python
ser = ser + 1
```

使用 `Series.apply(func)` 可以把函数应用到 Series 的每一个元素，返回值组成新的 Series。

![](assets/247740835/8a1249b0d46a.png)

## DataFrame

### 概述与创建

DataFrame 是包含行标签（`index`）和列标签（`columns`）的二维表格。

- `values`：以 NumPy 多维数组形式返回数据值。
- `index`：行索引对象。
- `columns`：列标签对象。
- `dtypes`：各列的数据类型。
- `shape`、`size`、`ndim`：分别返回形状、元素总数和维度数。

```python
pandas.DataFrame(
    data=None,
    index=None,
    columns=None,
    dtype=None,
    copy=None,
)
```

- `data`：可以是 ndarray、Iterable、字典或 DataFrame。
- `index`：行标签，可以是 Index 或 array-like。
- `columns`：列标签，可以是 Index 或 array-like。

![](assets/247740835/beea989398c3.png)

![](assets/247740835/aab05baf5f7e.png)

### 查询

- 列查询：`df["列名"]`，返回 Series。
- 行查询：`df.loc["行标签"]`。
- 位置查询：`df.iloc[行号, 列号]`。
- 切片查询：例如 `df.loc["行1":"行3"]`。

![](assets/247740835/b8da33bbb0b2.png)

### 增加和更新

```python
df["a"] = df["b"] + df["c"]
df["a"] = 1
```

当 `a` 列不存在时会创建该列；已经存在时会更新该列。

基于条件赋值：

```python
df.loc[df["a"] - df["b"] > 10, "c"] = 1
df.loc[df["a"] - df["b"] <= 10, "c"] = 0
```

### 删除

```python
df.drop(labels=..., axis=..., inplace=...)
```

- `axis=0` 删除行，`axis=1` 删除列。
- `inplace=True` 直接修改原数据，否则返回新副本。

## 时间序列数据

Pandas 的时间序列支持主要涉及时间点（Timestamp）和时间差（Timedelta）。

### Timestamp

- 表示具体时间点，可精确到纳秒。
- 使用 `pd.Timestamp()` 创建，参数可以是日期字符串、具体年月日或整数时间戳等。
- 常用属性包括 `year`、`month`、`day`、`hour`、`week`、`dayofweek`、`is_leap_year`。

![](assets/247740835/52b4e35d8f8a.png)

![](assets/247740835/9c405a2a85d0.png)

![](assets/247740835/bd7e74be5b68.png)

当 DataFrame 的索引是 Timestamp 时，可以通过 `at_time()` 选择特定时间，通过 `between_time()` 选择时间段。

![](assets/247740835/c8389375c9e7.png)

### Timedelta

Timedelta 表示时间长度或差值，而不是具体时间点。

![](assets/247740835/123ee02f4e1a.png)

使用 `to_datetime()` 可以把字符串或其他格式的日期列转换为 Pandas 的标准日期时间对象。

## 透视表与交叉表

### 透视表

透视表是“分组 + 聚合”的封装：

```python
pd.pivot_table(
    data,
    values=...,
    index=...,
    columns=...,
    aggfunc=...,
)
```

- `index`：行分组键。
- `columns`：列分组键。
- `values`：需要聚合的数据列。
- `aggfunc`：聚合函数，默认为 `mean`，常用 `sum`。

![](assets/247740835/693b35e20748.png)

### 交叉表

交叉表是一种特殊的透视表。参数可以直接使用数组、列表或 Series；只要长度一致，也可以交叉统计来自不同 DataFrame 的数据。

```python
pd.crosstab(index, columns, ...)
```
