## 相关概念、工具

### 云服务是什么

#### 课程核心

学习如何把原来在自己电脑上运行的应用，部署或迁移到云端服务器上，并让别人通过网络访问。

#### “云”概念

“云”本质上是将算力、存储、内存、网络等计算资源集中到远程服务器中，并根据实际需求进行弹性分配和伸缩。开发完成的软件和程序可以部署并运行在这些云资源上；当系统规模扩大到多个软件、多个服务甚至多个服务器时，还需要对这些资源和服务进行统一的管理、调度和规范化运维。

### VMware 是什么

VMware 用来在 Windows 内部创建一台虚拟计算机，运行 CentOS Stream 10，用作模拟的 Linux 云服务器。

### MobaXterm 是什么

Windows 上远程操作 Linux 服务器的软件。

通过 SSH 实现远程执行 Linux 命令，还可以借助其中的 SFTP 实现 Windows 与 Linux 之间相互传输文件。

### NAT 是什么

让虚拟机能够共用宿主机的网络连接互联网。

### JDK 是什么

Java Development Kit，Java 开发工具包。

提供开发、编译、运行 Java 程序的一整套 Java 工具。

### Vim 是什么

Vim 是 Linux 中常用的文本编辑器，运行在终端中。

常见操作：

| 操作 | 含义 |
| --- | --- |
| `i` | 进入编辑模式，可以输入文字 |
| `Esc` | 退出编辑模式 |
| `:wq` | 保存并退出 |
| `:q!` | 不保存，强制退出 |

## 配置固定 IP

### 为什么服务器要固定 IP？

CentOS 最开始通过 DHCP 自动获得：`192.168.189.128`。

DHCP 的特点是自动分配 IP，但地址以后可能改变；后续访问这台服务器需要一个**固定 IP（Static IP）**。

### 查看 CentOS 网卡

执行 `nmcli connection show`，得到：

```plain
NAME     TYPE       DEVICE
ens160   ethernet   ens160
lo       loopback   lo
```

因此当前主要网卡为 `ens160`。

### 找到 NetworkManager 配置文件

执行：

```bash
ls -l /etc/NetworkManager/system-connections/
```

找到：`ens160.nmconnection`。

因此实际配置文件为：

```plain
/etc/NetworkManager/system-connections/ens160.nmconnection
```

### 编辑固定 IP

使用 Vim：

```bash
sudo vim /etc/NetworkManager/system-connections/ens160.nmconnection
```

找到 `[ipv4]`，修改 IPv4 相关配置：

```plain
[ipv4]
method=manual
dns=114.114.114.114;
address1=192.168.189.100/24,192.168.189.2
```

这些配置分别表示：

| 配置 | 含义 |
| --- | --- |
| `method=manual` | 不使用 DHCP，改成人工指定 IP |
| `192.168.189.100` | CentOS 的固定 IP |
| `/24` | 子网掩码为 `255.255.255.0` |
| `192.168.189.2` | VMware NAT 网关 |
| `114.114.114.114` | DNS 服务器 |

保存：

```plain
Esc
:wq
Enter
```

### 重新加载网络配置

执行：

```bash
sudo nmcli connection reload
```

作用：让 NetworkManager 重新读取刚才修改的配置文件。

```bash
sudo nmcli connection up ens160
```

作用：按新的配置重新启动 `ens160` 网络连接。

### 检查固定 IP

执行：

```bash
ip addr show ens160
```

看到：

```plain
inet 192.168.189.100/24
```

说明固定 IP 已经生效。固定 IP 配置完成以后，即可通过 MobaXterm 配置 SSH 进行远程操作。

## 实践：安装配置 JDK

### 准备与安装工作

通过 MobaXterm 内置的 SFTP 将 `jdk-8u481-linux-x64.tar.gz` 文件上传到 Linux 服务器中。

在 Linux 服务器中创建 Java 安装目录：

```bash
sudo mkdir -p /usr/local/java
```

解压 JDK：

```bash
sudo tar -zxvf /home/s1-liyihe/jdk-8u481-linux-x64.tar.gz -C /usr/local/java
```

使用完整目录验证本体：

```bash
/usr/local/java/jdk1.8.0_481/bin/java -version
```

### 配置 Java 环境变量

创建 Java 环境变量文件：

```bash
sudo vim /etc/profile.d/java.sh
```

写入：

```bash
export JAVA_HOME=/usr/local/java/jdk1.8.0_481
export PATH=$JAVA_HOME/bin:$PATH
```

保存退出：

```plain
Esc
:wq
Enter
```

加载配置：

```bash
source /etc/profile.d/java.sh
```

检查配置：

```bash
java -version
```
