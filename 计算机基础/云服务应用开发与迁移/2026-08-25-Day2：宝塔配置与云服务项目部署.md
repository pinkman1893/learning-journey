## 什么是宝塔

宝塔 BT Panel 是一个 Linux 服务器的可视化运维管理工具。

可以给 Linux 服务器安装一个可视化的网页管理后台，直接在浏览器里访问管理，以代替传统复杂的纯终端操作。

## 实践 2：云服务项目开发部署

### 相关概念

#### Maven

Maven 是 **Java 项目依赖文件管理器**和**自动构建工具**，用于自动化管理 Java 项目的依赖、编译和打包。

- 如果没有 Maven，需要自己寻找 `.jar` 依赖包、下载并放进项目、配置变量路径、编译打包。
- 使用 Maven，只需要编写一个 `pom.xml`，告诉 Maven 项目名称、使用版本、所需依赖以及打包方式。

![](assets/282608837/0ec3440a7cf7.png)

#### Spring Boot

Spring Boot 是快速搭建 Java 服务程序的常用框架。

#### Spring Web

Spring Web 是 Spring Boot 中专门负责 **Web / HTTP 开发**的功能模块。

勾选 Spring Web 即为告知这个 Spring Boot 项目要用于 Web / API 服务，并使用其提供的相关能力。

#### YAML

Spring Boot 的配置文件建议选择 YAML 格式。

YAML 使用键值对配置属性，并使用缩进表示层级：

```yaml
server:
  port: 8081
```

> 键值对的冒号后面要加空格。

#### JAR 文件的三种启动方式

JAR 文件是 Java 程序的打包文件，常见启动方式有：

1. `java -jar xxx.jar`：最普通的前台运行。该终端会一直被程序占用；关闭终端或按下 `Ctrl + C`，程序也会随之关闭，适合用于测试和观察日志。
2. `java -jar xxx.jar &`：`&` 表示将程序放到后台运行，终端不会被占用，可以在同一终端中陆续启动多个服务。
3. `nohup java -jar xxx.jar &`：`nohup` 表示不让程序因当前终端断开而终止，可以使服务在后台持续运行，防止 SSH 断开等情况终止服务。

Linux 的后台任务管理：

- `jobs`：查看当前终端中的后台任务编号。
- `fg 编号`：将对应的后台任务拉回前台，之后可以按下 `Ctrl + C` 停止服务。
- 关闭持续运行的服务时，可以找到进程 PID 后使用 `kill` 命令停止进程。

### 安装部署过程

1. 在 Windows 主机上安装 JDK、IDEA、Maven。
2. 进入 IDEA，选择 Spring Boot 项目。
   1. 服务器 URL 设置为 `https://start.aliyun.com`。服务器 URL 是 Spring Boot 项目初始化服务的地址，阿里云提供面向国内环境的 Spring Initializr 服务，使用较为方便。
   2. 语言选择 Java、类型选择 Maven、打包选择 JAR、配置选择 YAML，并选择本机的 JDK。

![](assets/282608837/5ab2c7fe4ed0.png)

3. 选择 Spring Web 项目。

![](assets/282608837/10a815656802.png)

4. 初始化完成后，修改 `pom.xml` 文件，注释掉 `<skip>true</skip>`。这样可以避免跳过 Spring Boot Maven Plugin 的重新打包过程，使 Maven 最后生成可通过 `java -jar` 直接启动的可执行 JAR 文件。

![](assets/282608837/76a1f523850f.png)

5. 进行项目开发。
6. 开发完成后，使用 Maven 打包；完成后会在项目的 `target` 目录生成 JAR 文件。

![](assets/282608837/fc5c1b36d745.png)

![](assets/282608837/06e1db419cb8.png)

7. 通过 MobaXterm 的 SFTP 将 JAR 文件上传到服务器上。
8. 在 JAR 文件所在目录执行：

```bash
java -jar xxxx.jar
```

9. 最后，在宝塔面板的“安全”中添加放行端口，让外部机器可以通过该端口访问服务。

![](assets/282608837/865a96824c3c.png)

## 项目发布的访问范围

### 本地访问：localhost 或 127.0.0.1

```text
http://localhost:8081/hello/name
http://127.0.0.1:8081/hello/name
```

`localhost` 和 `127.0.0.1` 都代表当前这台机器本身。

### 局域网 IP 访问：服务器私有 IP

```text
http://192.168.189.100:8081/hello/name
```

只要客户端与服务器处在同一个局域网内且网络可达，就可以通过服务器私有 IP 访问，例如学校内网中的访问。

### 公网 IP 访问：独立公网 IP 或公网映射

```text
http://<公网 IP>:8081/hello/name
```

外部用户即使不在同一个局域网，也可以通过公网访问服务器。如果已经配置了其他端口到 `8081` 的映射，则使用映射后的公网端口。
